# 생성형 AI 코딩 — 초급자 15주 교안 (1학년 1학기 신입생용)

코딩을 전혀 모르고 컴퓨터 활용도 서툰 **1학년 1학기 신입생**이, 서두르지 않고 **AI를 활용하며** 코딩에 서서히 익숙해지도록 만든 15주 교안입니다.
**AI 시대에 AI를 활용하고 이끄는 컴퓨터 엔지니어**로 성장하기 위한 기초 체력을 기르는 것이 목표입니다.

## 수업 방식 — Antigravity와 "두 레인"

모든 실습은 **구글 Antigravity(안티그래비티)** 의 AI 에이전트와 함께 하며, **"시키기"와 "확인하기"를 일부러 분리**해서 진행합니다.

| 🅿️ 프롬프트 파트 (AI에게 시키기) | 🅲 코드 파트 (결과 확인하기) |
|:--|:--|
| 요구 정리표 → 프롬프트 작성 → **🅿️ 프롬프트 점검표** → 에이전트에 보내기 → **계획서(아티팩트) 읽고 승인** | 파일 확인 → **동작 점검표(예상 결과를 먼저 적고 실행)** → 코드 읽기(기준 코드) → **🅲 코드 점검표** + `git diff` → 고쳐 달라기/되돌리기 |
| 질문: *내 요구를 정확히 전했나?* | 질문: *AI가 만든 것이 정말 맞나?* |

```text
🧠 개념 파트(왜?) → 🅿️ 프롬프트 파트(시키기) → 🅲 코드 파트(확인하기) → 💾 올리기·내 것으로 → 💪 도전 A·B
```

- 한 번에 하나씩, **범위를 좁혀서** 시키고, **먼저 계획을 보여 달라**고 합니다.
- **프롬프트는 코드가 아니라 일상어로** 씁니다. 파일 이름·버튼 이름표·색 코드처럼 *정확히 맞아야 하는 약속*만 쉬운 코드 표현으로 적습니다.
- AI가 만든 코드는 교안의 **기준 코드**와 달라도 됩니다. **동작 점검표를 통과하는지**가 기준입니다.
- Git 명령(`add/commit/push`)은 일부러 **학생이 직접** 입력합니다.
- 한 장 요약: [부록 · 두 레인 카드](md/appendix-two-lanes.md)

- 그림·표·비유·단계별 설명을 풍부하게 넣었습니다.
- 주차마다 **새로 나오는 용어는 "📖 새 용어 풀이" 표**로 설명합니다.
- 주차 끝에는 **💪 도전 A·B** (우수 학생용 중급 확장 2개)가 있습니다.
- 동일 학기에 병행되는 **HTML+CSS+JS 3학점**, **Python 3학점** 과목의 진도와 맞추어 테마를 구성했습니다.

## 폴더 구조

| 폴더 | 내용 |
|:--|:--|
| `src/` | 교안 원본 (`{{code: 경로}}` 로 예제 코드를 불러옴) |
| `md/` | `tools/build.py` 로 만든 완성 교안 |
| `code/` | **동작을 확인한 예제 코드** (주차별 `w03` ~ `w14`) |
| `tools/build.py` | `src/` → `md/` 변환 스크립트 |

```bash
python3 tools/build.py      # src/*.md → md/*.md
```

## 예제 코드 확인 상태

- 웹 예제(`w03`~`w07`)는 브라우저(Chromium)에서 열어 **클릭·결과 화면·다시 하기까지 동작**을 확인했습니다.
- 파이썬 예제(`w09`~`w14`)는 입력을 흘려 넣어 **실행 결과·파일 저장·자동 확인(`check_quiz.py`)** 을 확인했습니다.
- 도전 A·B의 코드 조각도 대부분 실행해 동작을 확인했습니다.
- 각 주차의 **"일부러 틀려 보기" 실험**(예: `fox`→`fx`, `<` → `<=`, `>=` → `>`)도 실행해 교안에 적은 **에러·결과가 실제로 나오는지** 확인했습니다.
- **프롬프트 자체는 실제 Antigravity에서 실행해 보지 못했습니다.** AI의 출력은 매번 다르므로, 수업 전에 교수자가 각 주차 프롬프트를 한 번 시험해 보고 필요하면 문구를 조정해 주세요. (그래서 교안은 AI 결과가 기준 코드와 달라도 되도록 *동작 점검표* 중심으로 구성했습니다.)
