# 15주차 · 기말고사 — 필기시험 + 포트폴리오 발표

> 🎯 **이번 주 목표**
> 1. 9~14주에 배운 **파이썬**과 1~8주의 기본기를 **필기시험**으로 점검한다.
> 2. 한 학기 동안 만든 **나만의 작품 2개**(웹 성격 테스트, 파이썬 퀴즈 게임)를 **포트폴리오 발표**로 소개한다.

## 2. 필기시험 안내

- **시간 40분**, 객관식·단답·코드 읽기·에러 읽기·서술 (연습 문제는 4절)
- 코드는 **읽고 결과를 말하는** 문제예요. 쓰는 문제는 나오지 않아요.
- **AI·노트북·휴대폰 사용 불가.**

### 📚 9~14주 핵심 지도

| 주 | 주제 | 반드시 알아야 할 것 | 자주 하는 실수 |

| 9 | 첫 대화 | `print`/`input`, 변수, 숫자로 바꾸기, `//` `%`, 에러 읽기 | `input` 이 **글자**라는 것을 잊음 |
| 10 | 조건문 | `if/elif/else`, `==` 와 `=`, `random`, 들여쓰기 | `=` 와 `==` 혼동 |

| 12 | 리스트·딕셔너리 | 번호 0부터, `["이름표"]`, `for … in` | 이름표 철자 오류 |

## 4. 연습 문제 (필기 · 정답은 수록하지 않았어요)

**[객관식]**
1. `input()` 으로 받은 값의 자료형은? ① 정수 ② 소수 ③ 글자(문자열) ④ 참/거짓
2. `7 // 2` 의 결과는? ① 3.5 ② 3 ③ 1 ④ 4
3. `range(2, 5)` 가 만드는 숫자는? ① 2,3,4,5 ② 2,3,4 ③ 3,4,5 ④ 2,5
4. 파이썬에서 **같다**를 묻는 기호는? ① `=` ② `==` ③ `!=` ④ `=>`
5. 파일에 **기존 내용을 지우고 새로** 쓰는 모드는? ① `"r"` ② `"a"` ③ `"w"` ④ `"x"`
6. AI에게 *"예상 결과는 내가 적은 값 그대로 써. 바꾸지 마."* 라고 하는 이유는? ① 답이 짧아져서 ② AI가 **통과시키려고 정답지를 몰래 바꾸는 것**을 막으려고 ③ 비용이 줄어서 ④ 설명이 쉬워져서

**[단답]**
7. `x = 5` 와 `x == 5` 의 차이를 한 줄로 쓰시오.
8. `quiz = {"question": "수도는?", "answer": "서울"}` 에서 **정답을 꺼내는 코드**를 쓰시오.
9. 함수에서 `print` 와 `return` 의 차이를 한 줄로 쓰시오.

**[코드 읽기]** 출력을 쓰시오.
10.
```python
total = 0
for i in range(1, 4):
    total = total + i
print(total)
```
11.
```python
def double(n):
    return n * 2

result = double(5) + double(3)
print(result)
```
12. 아래 코드에서 에러가 나는 줄은 어디이고 에러 종류는 무엇인가? (이유도 쓰시오)
```python
fruits = ["사과", "바나나"]
print(fruits[2])
```

**[서술]**
13. 프로그램을 껐다 켜도 **최고 점수가 남게** 하려면 어떻게 해야 하는지, 필요한 단계를 순서대로 쓰시오. (파일이 처음에는 없는 상황도 고려)
14. *"숫자 맞히기 게임을 최대 5번까지 도전하게 바꾸고 싶다"* 를 AI에게 시키는 프롬프트를 **코드를 쓰지 않고** 일상어로 써 보시오. (무엇을 바꾸는지, 지켜야 할 것, 하지 말 것, 계획 먼저를 포함)
15. AI가 만든 프로그램이 맞게 동작하는지 확인하는 방법을 **세 가지** 쓰시오. (예: 예상 결과, 경계값, 자동 확인 중에서)
