## 2. 🧠 개념 파트 · 성격 테스트는 어떻게 결과를 정할까? (35분)

### 2-1. 원리: "표(점수) 모으기"

> 🧠 **비유: 학급 투표**
> 질문마다 **선택지**가 있고, 선택지는 *"이 동물에게 1표!"* 를 줘요. 끝나고 **표가 가장 많은 동물**이 내 결과가 됩니다.

```text
  질문1: 쉬는 날 나는?   ┌ A. 집에서 뒹굴뒹굴  → 🐱 고양이 +1
                         └ B. 친구들과 놀기    → 🐶 강아지 +1

  질문2: 처음 보는 사람? ┌ A. 조용히 지켜본다  → 🐰 토끼 +1
                         └ B. 먼저 말을 건다   → 🦊 여우 +1
         ...

  끝!  점수판:  🐱 2   🐶 1   🐰 1   🦊 0   →  제일 높은 건? 🐱 고양이!
```

### 2-2. 🧪 활동 1 · 종이에 설계하기 (10분)

코드를 쓰기 전에 **종이(또는 메모장)** 에 먼저 설계해 보세요. (설계가 곧 코딩의 절반이에요!)

| 질문 번호 | 질문 | A 선택지 → 동물 | B 선택지 → 동물 |
|:--:|:--|:--|:--|
| 1 | 쉬는 날, 나는? | 집에서 뒹굴뒹굴 → 🐱 | 친구들과 놀기 → 🐶 |
| 2 | | | |
| 3 | | | |
| 4 | | | |

> 💡 **같은 동물이 여러 번 나와도 좋아요.** 한 동물이 너무 많이 나오면 결과가 쏠리니, 4종류가 **골고루** 나오게 짜 보세요.

### 2-3. 새로 배우는 JS 도구 2가지

> 📖 **새 용어 풀이**
> | 용어 | 쉬운 뜻 | 예 |
> |:--|:--|:--|
> | **객체(object)** | **이름표(키) : 값** 으로 이루어진 서랍장 | `{ type: "cat", label: "뒹굴뒹굴" }` |
> | **속성 꺼내기** | 점(`.`)으로 서랍을 열어요 | `q.text` → 질문 글 |
> | **반복문 `for…in`** | 객체의 이름표를 **하나씩 꺼내며** 반복 | 점수판의 동물을 차례로 살펴볼 때 |

```text
 객체 = 라벨 붙은 서랍장
  ┌─────────────────────────┐
  │ text :  "쉬는 날, 나는?"   │  ← 이름표 text 서랍
  │ a    :  { label, type }   │  ← 서랍 안에 또 서랍!
  │ b    :  { label, type }   │
  └─────────────────────────┘
  question.text      → "쉬는 날, 나는?"
  question.a.label   → A 선택지의 글
```

### 라운드 3 🅿️ — 점수 더하기와 결과 보여 주기 (`if`·`for…in`)

**요구 정리표**

| 상황 | 해야 할 일 |
|:--|:--|
| 선택지를 누름 | 그 선택지의 동물 점수를 **+1**, 질문 번호도 +1 |
| 질문이 남아 있음 | 다음 질문을 보여 줌 |
| 질문이 끝남 | 질문 구역은 숨기고 결과 구역을 보여 주며, "당신은 'cat' 타입이에요!" 처럼 결과를 표시 |
| 결과 동물 | 점수판에서 **가장 높은 점수의 동물**을 찾아 알려 주는 작은 기능 (동점이면 먼저 나온 동물) |

> 🤖 **프롬프트 ③ (클릭·점수·결과)**
> ```text
> week06 의 quiz.js 에 기능을 추가해 줘. 이미 있는 질문 목록, 점수판, 질문 보여 주기는 바꾸지 마.
>
> 1. 선택 버튼(A 또는 B)을 누르면, 그 선택지의 동물 점수를 1점 올리고 다음 질문으로 넘어가 줘.
> 2. 질문이 남아 있으면 다음 질문을 보여 주고, 마지막 질문까지 끝났으면 질문 구역은 숨기고 결과 구역을 보여 줘.
>    결과 글은 "당신은 'cat' 타입이에요!" 처럼 가장 점수가 높은 동물 이름을 넣어서 보여 줘.
> 3. 가장 점수가 높은 동물을 찾는 일은 이름을 붙인 작은 기능으로 따로 만들어 줘. 점수가 같으면 먼저 나온 동물로 해 줘.
>
> 한 줄마다 한국어 설명을 달아 줘. 먼저 계획을 보여 주고, 내가 확인하면 고쳐 줘.
> ```

**점검표** ✅ — 기존 코드를 **"바꾸지 마"** 라고 했나? / **동점 규칙**을 적었나? / 질문이 끝나는 **조건**을 정확히 적었나?

## 4. 🅲 코드 파트 · 테스트가 제대로 도는지 확인하고 읽기 (55분)

### 4-1. 🅲 동작 점검 — "정답을 알고 눌러 보기"

결과를 **미리 예상**하고 눌러 보세요. (답이 정해지는 입력으로 테스트해야 AI의 실수를 잡아낼 수 있어요!)

| # | 선택 순서 | 예상 결과 | 실제 | ✔ |
|:--:|:--|:--|:--|:--:|
| 1 | 4개 모두 **A** | 점수 `cat 2, rabbit 2` → 동점이면 **먼저 나온 cat** | | ☐ |
| 2 | **A, B, B, B** | `fox 2` 가 가장 높아서 **fox** | | ☐ |
| 3 | 질문마다 **진행 `1 / 4` → `4 / 4`** 로 늘어난다 | | | ☐ |
| 4 | 4번째 질문 뒤 **질문 영역이 사라지고 결과 영역**이 보인다 | | | ☐ |
| 5 | `F12` Console 에 **빨간 에러가 없다** | | | ☐ |

> 🔎 **점수판을 눈으로 확인하는 방법**: 결과가 나온 뒤 `F12 → Console` 에 **`scores`** 를 입력하고 Enter 하면 `{cat: 2, dog: 0, rabbit: 2, fox: 0}` 처럼 **점수판이 그대로 보여요.** 예상과 다르면 점수 계산 코드가 틀린 거예요!
