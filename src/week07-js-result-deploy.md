## 2. 🧠 개념 파트 · 결과 사전과 "상태 되돌리기" (25분)

### 2-1. 결과 사전 — "결과 정보도 데이터로 정리한다"

지금은 결과가 `당신은 'cat' 타입이에요!` 라고만 나오죠? **이모지·제목·설명**을 담은 **결과 사전**을 만들면 훨씬 근사해져요.

```text
 results (결과 사전)
  ┌──────────────────────────────────────────────────────┐
  │ cat    → { emoji:🐱, title:"느긋한 고양이", desc:"..." }   │
  │ dog    → { emoji:🐶, title:"활발한 강아지", desc:"..." }   │
  │ rabbit → { emoji:🐰, ... }                               │
  │ fox    → { emoji:🦊, ... }                               │
  └──────────────────────────────────────────────────────┘
   results["cat"].title   →  "느긋한 고양이"
```

> 🧠 **비유: 연락처 앱** 이름(`cat`)을 검색하면 그 사람의 **사진·소개·번호**가 한꺼번에 나오죠? `results` 도 이름표 하나로 **여러 정보를 한 번에** 꺼내는 사전이에요.

> 📖 **새 개념: 데이터와 화면의 분리** *"무엇을 보여줄지"(데이터 = `results`)* 와 *"어떻게 보여줄지"(코드 = `showResult`)* 를 **나눠 두면**, 결과 문구를 바꾸고 싶을 때 **데이터만** 고치면 돼요. (이 생각은 파이썬 테마에서도 또 나와요!)

### 2-2. 상태(State)와 다시 하기

> 🧠 **비유: 게임 리셋 버튼** *다시 하기*를 누르면 **점수도, 스테이지도 처음으로** 돌아가죠? 우리 프로그램이 기억하는 것(**상태**)은 `scores`(점수판)와 `current`(질문 번호) 두 가지예요. 둘을 **처음 값으로** 되돌리면 리셋이에요.

> 📖 **새 용어** | **상태(State)**: 프로그램이 **지금 기억하고 있는 값들**. 상태가 바뀌면 화면도 바뀌어야 해요. | **초기화(리셋)**: 상태를 처음 값으로 되돌리는 것.

> 📖 **`const` vs `let`**: `const` 상자는 **새 값을 다시 담을 수 없어요.** 점수판을 통째로 새로 담아야 하면 `let` 이어야 해요. *(AI가 자주 놓치는 부분이에요!)*

## 💪 도전 A · B (우수 학생용 중급 확장)

> 🧭 **도전도 두 레인으로!** ① 🅿️ **프롬프트 점검표**를 지켜 Antigravity에게 시키고 → ② 🅲 **코드 점검표**로 결과를 확인하세요. *(AI가 준 코드가 안 돌아가면 에러 메시지를 붙여 넣어 고치고, 마지막에 **내 말로 코드를 설명**해 보세요.)*
> ✍️ **프롬프트는 코드가 아니라 일상어로!** 아래 코드 조각은 *읽고 이해하기 위한 예시*예요. AI에게는 코드를 붙여 넣지 말고 **"무엇을 어떻게 되게 하고 싶은지"** 를 말로 설명해서 시켜 보세요.

### 💪 도전 A · "결과 공유 버튼"
결과 카드에 **"결과 복사하기"** 버튼을 만들어, 친구에게 붙여 넣을 수 있는 문장을 클립보드에 복사해 보세요.

```javascript
const shareButton = document.getElementById("share-button");

shareButton.addEventListener("click", function () {
  const info = results[pickResult()];
  const text = "나는 " + info.emoji + " " + info.title + " 타입이래! " + location.href;
  navigator.clipboard.writeText(text);
  alert("복사했어요! 친구에게 붙여 넣어 보세요 😊");
});
```
- `navigator.clipboard.writeText(글자)` : 글자를 **복사**해 주는 도구
- `location.href` : **지금 이 페이지의 주소**

**목표**: ① HTML에 `<button id="share-button">📋 결과 복사하기</button>` 를 결과 영역에 추가 ② **GitHub Pages(https 주소)** 에서 동작을 확인 (파일을 직접 열었을 때는 복사가 막힐 수 있어요) ③ 복사에 성공했을 때 버튼 글자가 *"복사 완료!"* 로 잠깐 바뀌게 만들기

## 🧑‍🏫 교수자 메모
- 오늘은 테마①의 **마무리**입니다. 학생 작품을 **돌려 가며 체험**하게 하면 성취감이 큽니다.
- `const` → `let` 변경 누락으로 *"Assignment to constant variable"* 에러가 흔합니다. Console 에러 읽기를 다시 연습시키세요.
- 중간고사 안내는 **부담을 줄이는 방향**으로 전달하세요. 실기시험 없이 **필기 + 내 작품 발표**임을 강조하세요.
- 시험 키트(문제·모범답안·채점 도구)는 별도 보관하며, 이 교안에는 포함하지 않습니다.
- **두 레인 운영**: 🅿️ 프롬프트 파트에서는 학생이 **점검표를 보내기 전에 체크**하게 하고, 🅲 코드 파트에서는 **예상 결과를 먼저 적은 뒤** 실행하게 하세요. AI가 약속(파일 범위·이름표·철자)을 어긴 사례는 학급 전체가 배우는 좋은 재료입니다.
- Antigravity의 화면·설정 이름은 버전마다 달라질 수 있습니다. 수업 직전에 **Planning/실행 전 물어보기** 설정이 유지되는지 한 번 확인하세요.
