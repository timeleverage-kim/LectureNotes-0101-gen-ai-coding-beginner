# 8주차 · 중간고사 — 필기시험 + 내 작품 발표

> 🎯 **이번 주 목표**
> 1. 1~7주차에 배운 내용을 **필기시험**으로 정리·점검한다.
> 2. 지금까지 **내가 만든 작품**(나의 소개 페이지, 동물 성격 테스트)을 **발표**로 친구들과 나눈다.
> 3. AI를 *"믿고 맡기는 도구"* 가 아니라 *"확인하며 쓰는 도구"* 로 썼던 경험을 **내 말로 설명**한다.

> 🔒 이 문서는 **학생용 안내와 연습 문제**입니다. 연습 문제의 **모범 답안·정답은 수록하지 않았고**, 실제 시험 문제와 채점 기준(시험 키트)은 교수자만 보관합니다.

| 항목 | 내용 |
|:--|:--|
| 시험 범위 | **1~7주** (AI·프롬프트, 폴더·Git, HTML·CSS·JavaScript, 성격 테스트 사이트) |
| 시간 | 3시간 (180분) |
| 평가 방식 | **필기시험 + 발표 평가** (실기시험은 보지 않아요!) |
| 준비물 | 노트북+충전기, 내 사이트 주소(휴대폰으로도 열려야 해요), 필기구 |

> 🧠 **비유: 운전면허 시험이 아니라 "작품 발표회"** 필기에서 *알고 있는지*를 확인하고, 발표에서 *내가 직접 만든 것을 설명할 수 있는지*를 봐요. 그 자리에서 새로 코딩하는 시험은 없어요. **내가 만든 것을 내 말로 설명하는 것**이 가장 큰 실력이에요.

## 2. 필기시험 안내

- **시간 40분**, 객관식·단답·코드 읽기·서술 (연습 문제는 4절)
- 코드는 **쓰는 문제가 아니라 읽는 문제**예요. (예: *"이 코드를 실행하면 화면에 무엇이 나올까요?"*)
- **AI·노트북·휴대폰 사용 불가.** 필기구만 가져오세요.

### 📚 1~7주 핵심 지도

| 주 | 주제 | 반드시 알아야 할 것 | 자주 하는 실수 |
|:--:|:--|:--|:--|
| 1 | AI와 도구 | AI = 다음 말 맞히기, **프롬프트 4재료**, **환각**, 안전 수칙, 챗 앱 vs 에이전트 | AI를 그대로 믿기 |
| 2 | 컴퓨터·Git | 폴더·확장자, `git add/commit/push`, 커밋 꼬리표, **`git diff` 의 쓰임** | 확장자가 `.txt`, push 안 함 |
| 3 | HTML | 태그(여닫기), `head/body`, 제목·문단·목록·그림·링크 | 닫는 태그 빠뜨림 |
| 4 | CSS | `선택자 { 속성: 값; }`, 박스 모델, class(`.`) | `;` `}` 빠뜨림 |
| 5 | JS 기초 | 변수, 함수, 이벤트, 이름표(`id`), 배열, `if` | `<script>` 위치, 이름표 철자 |
| 6 | 성격 테스트 | 객체·배열, 점수 누적, 숨기기/보이기 | 동물 이름 철자 불일치 |
| 7 | 결과·공개 | 데이터와 코드 분리, 상태 초기화, README, 배포 | `const` 에 다시 담기 |

**AI 활용에 관한 단골 질문**: ① 프롬프트 4재료는? ② AI가 **약속을 어겼는지** 어떻게 확인하나요? (실행·예상 결과·`git diff`) ③ 프롬프트에 **"건드리지 말 것"** 을 적는 이유는? ④ 에러가 났을 때 AI에게 **무엇을 붙여 넣나요?**

발표에서는 **내가 AI에게 한 말(프롬프트) 하나**를 소개해요. 아래 칸을 채워 보세요.

| 칸 | 내 대답 |

## 4. 연습 문제 (필기 · 정답은 수록하지 않았어요)

**[객관식]**
1. AI가 문장을 만드는 방식을 가장 잘 설명한 것은? ① 인터넷에서 정답을 복사 ② 다음에 올 말을 예측해 이어 붙임 ③ 미리 쓴 답변 중 선택 ④ 사람이 실시간으로 입력
2. AI가 쓴 코드를 받았을 때 가장 알맞은 태도는? ① 바로 제출 ② 자신 있게 말했으니 믿음 ③ **실행해서 확인**한 뒤 사용 ④ 다른 AI에게 "맞아?"만 물어보고 끝
3. 이번 저장에 **넣을 파일을 고르는** Git 명령은? ① `git status` ② `git add` ③ `git push` ④ `git log`
4. HTML에서 **번호가 붙은 목록**을 만드는 태그는? ① `<ul>` ② `<ol>` ③ `<li>` ④ `<p>`
5. CSS 규칙 `h1 { color: red; }` 에서 `color` 는? ① 선택자 ② 속성 ③ 값 ④ 태그
6. AI에게 시킬 때 **"이미 있는 제목은 바꾸지 마"** 처럼 건드리지 말 것을 적는 가장 큰 이유는? ① 답이 빨라져서 ② AI가 **엉뚱한 곳까지 바꾸는 것**을 막으려고 ③ 비용이 줄어서 ④ 계획서가 필요 없어져서

**[단답]**
7. 박스 모델의 **네 가지 요소**를 안쪽부터 쓰시오.
8. JS에서 `colors = ["a", "b", "c"]` 일 때, `colors[1]` 의 값과 `colors.length` 의 값은?
9. `let` 과 `const` 의 차이를 한 줄로 쓰시오.
10. AI가 만든 결과가 **내 약속과 다른지** 확인하는 방법 **두 가지**를 쓰시오.

**[코드 읽기]** 출력(또는 화면 변화)을 쓰시오.
11. (JavaScript)
```javascript
let count = 0;
count = count + 1;
count = count + 1;
console.log("횟수: " + count);
```
12. (JavaScript)
```javascript
const scores = { cat: 2, dog: 3 };
scores.cat = scores.cat + 2;
console.log(scores.cat, scores.dog);
```
13. (HTML/CSS) 아래에서 글자 색이 파란색이 되는 요소는 무엇이며 이유는?
```html
<style> .tip { color: blue; } </style>
<p class="tip">안녕</p>
<p>반가워</p>
```

**[서술]**
14. AI가 만들어 준 코드를 **그대로 믿으면 안 되는 이유**를 쓰고, 이를 막는 **확인 방법 두 가지**를 쓰시오.
15. *"버튼을 누르면 횟수가 늘어나는 페이지"* 를 AI에게 시키려 한다. **코드를 쓰지 않고** 일상어로 프롬프트를 써 보시오. (역할·목표·조건·계획 먼저를 포함)
