## 2. 🧠 개념 파트 · CSS란? (35분)

### 2-1. CSS = 웹페이지의 "옷"

> 🧠 **비유: 마네킹과 옷**
> HTML이 **마네킹(뼈대)** 이라면, CSS는 마네킹에게 입히는 **옷과 화장**이에요. 마네킹은 그대로인데 옷만 바꾸면 완전히 다른 분위기가 되죠? CSS도 **HTML은 하나도 안 바꾸고** 모양만 바꿉니다.

> 📖 **새 용어 풀이**
> | 용어 | 쉬운 뜻 |
> |:--|:--|
> | **CSS** | 웹페이지의 **모양**(색, 글꼴, 크기, 배치)을 정하는 언어 |
> | **선택자(selector)** | *"누구를 꾸밀까?"* — 꾸밀 대상을 고르는 이름 |
> | **속성(property)** | *"무엇을 바꿀까?"* — 색, 크기, 여백 같은 항목 |
> | **값(value)** | *"어떻게 바꿀까?"* — 빨강, 20px 같은 설정 |
> | **클래스(class)** | HTML 요소에 붙이는 **별명표**. CSS에서 `.별명` 으로 불러요 |

### 2-2. CSS 규칙의 모양

```text
   h1   {   color: blue;   }
   ↑         ↑      ↑
  선택자    속성    값
 (누구를?) (무엇을?)(어떻게?)

 → "모든 제목(h1)의 글자색(color)을 파랑(blue)으로 해 줘"
```

규칙은 이렇게 읽으면 돼요.

```css
선택자 {
  속성: 값;      ← 한 줄이 끝날 때마다 세미콜론(;) 꼭!
  속성: 값;
}
```

> ⚠️ **`;` 와 `{ }` 를 빼먹기 쉬워요.** CSS는 틀리면 **조용히 무시**돼서(에러 메시지 없음) 아무 일도 안 일어나요. 안 바뀔 땐 *세미콜론·중괄호·철자*부터 확인하세요!

### 2-3. HTML과 CSS 연결하기

CSS는 **별도 파일** `style.css` 에 쓰고, HTML의 `<head>` 안에서 **연결**합니다.

```html
<head>
  <meta charset="UTF-8" />
  <title>나의 소개 페이지</title>
  <link rel="stylesheet" href="style.css" />   ← 이 한 줄이 "옷 파일"과의 연결!
</head>
```

```text
 index.html  ──(link 로 연결)──▶  style.css
 (마네킹)                         (옷)
```

### 2-4. 색 표현하는 법 3가지

| 방법 | 예 | 설명 |
|:--|:--|:--|
| **색 이름** | `red`, `skyblue` | 쉽지만 종류가 한정돼요 |
| **16진수 코드** | `#3b5bdb` | `#` 다음에 6자리. 수천만 가지 색! |
| **rgb()** | `rgb(59, 91, 219)` | 빨강·초록·파랑을 0~255로 섞기 |

```text
 빛의 3원색 (RGB)
  🔴 Red + 🟢 Green + 🔵 Blue = 모든 색

  rgb(255, 0, 0)     → 🔴 빨강
  rgb(0, 0, 255)     → 🔵 파랑
  rgb(255, 255, 255) → ⬜ 흰색 (빛을 전부 더하면 흰색!)
  rgb(0, 0, 0)       → ⬛ 검정
```

> 🎨 색 코드는 **직접 외울 필요가 없어요.** 편집기에서 색 코드 옆의 작은 사각형을 클릭하면 **색 고르는 창**이 떠요. 또는 검색창에 *"color picker"* 를 입력하세요!

**① "이 규칙은 누구를 꾸밀까?" 선택자 읽기**

**② 속성 읽기**

| 속성 | 뜻 |
|:--|:--|

**③ 박스 모델 — 모든 요소는 상자예요**

```text
│  │  ┌──────── padding (안쪽 여백) ──────┐ │      │
│  │  │        내용 (글자, 그림)           │ │      │
│  │  └───────────────────────────────────┘ │      │
│  └────────────────────────────────────────┘      │
└──────────────────────────────────────────────────┘
```

### 4-3. 🧪 값만 바꿔 보기 (직접!) — "바꾸면 알게 돼요"

|:--|:--|:--|
| 둥근 정도 | `.card` 의 `border-radius: 20px` → `0px` / `40px` | 모서리 |
| 그림자 | `0 8px 24px` 의 숫자 | 번짐 |
| 글자 크기 | `font-size: 1.5rem` → `2rem` | 제목 크기 |
| **일부러 틀리기** | 한 줄의 `;` 를 지워 보기 | 에러 없이 **조용히 무시**돼요! |

> ⚠️ **CSS는 틀려도 에러 메시지가 안 나요.** 안 바뀌면 `;` `}` 철자부터 확인하세요!
> 📖 **rem이란?** 기본 글자 크기의 **몇 배**인지 나타내는 단위 (`1.5rem` = 1.5배).

## 💪 도전 A · B (우수 학생용 중급 확장)

> 🧭 **도전도 두 레인으로!** ① 🅿️ **프롬프트 점검표**를 지켜 Antigravity에게 시키고 → ② 🅲 **코드 점검표**로 결과를 확인하세요. *(AI가 준 코드가 안 돌아가면 에러 메시지를 붙여 넣어 고치고, 마지막에 **내 말로 코드를 설명**해 보세요.)*
> ✍️ **프롬프트는 코드가 아니라 일상어로!** 아래 코드 조각은 *읽고 이해하기 위한 예시*예요. AI에게는 코드를 붙여 넣지 말고 **"무엇을 어떻게 되게 하고 싶은지"** 를 말로 설명해서 시켜 보세요.

### 💪 도전 A · "CSS 변수로 한 번에 테마 바꾸기"
같은 색을 여러 군데에 반복해서 쓰고 있죠? **변수**를 만들면 한 곳만 바꿔서 전체 색을 바꿀 수 있어요.

```css
:root {
  --main-color: #3b5bdb;     /* 이름은 -- 로 시작 */
  --bg-color: #eef3ff;
}

h1 {
  color: var(--main-color);  /* var(변수이름) 으로 꺼내 쓰기 */
}

body {
  background-color: var(--bg-color);
}
```
**목표**: ① 파란색 `#3b5bdb` 이 쓰인 **모든 곳**을 `var(--main-color)` 로 바꾸기 ② `:root` 의 값 **한 줄만** 바꿔서 카드 전체 분위기 바꾸기 ③ **다크 모드 색 조합**(어두운 배경 + 밝은 글자)도 하나 만들어 보기

### 💪 도전 B · "마우스를 올리면 살아나는 카드"

```css
.card {
  transition: transform 0.3s;     /* 변화가 부드럽게 일어나게 */
}

.card:hover {
  transform: translateY(-6px);    /* 마우스를 올리면 위로 6px 떠오름 */
}
```
- `:hover` = **마우스를 올렸을 때**
- `transition` = 변화를 **부드럽게** (애니메이션)

**목표**: ① 카드가 떠오르도록 만들기 ② 링크 버튼(`.card a`)에도 `:hover` 로 색이 **더 진해지게** 하기 ③ `0.3s` 를 `1s` 로 바꾸면 어떻게 달라지는지 관찰해 한 줄로 적기
