## 2. 🧠 개념 파트 · 컴퓨터는 어떻게 "판단"할까? (40분)

### 2-1. 판단 = 참(True) / 거짓(False) 가르기

> 🧠 **비유: 놀이공원 키 제한**
> *"키가 120cm 이상이면 탈 수 있어요."* — 안내 직원은 **키를 재서(비교)** → **맞다/아니다(참/거짓)** 로 → **들여보낼지 말지** 결정하죠? 프로그램의 `if` 도 똑같아요.

```text
        ┌──────────────┐
        │ 조건을 검사한다 │   예) guess == answer ?
        └──────┬───────┘
          참 ✅ │         │ 거짓 ❌
      ┌────────▼───┐  ┌──▼──────────┐
      │ 이 일을 한다 │  │ 다른 일을 한다 │
      └────────────┘  └─────────────┘
```

> 📖 **새 용어 풀이**
> | 용어 | 쉬운 뜻 |
> |:--|:--|
> | **조건문 `if`** | *"만약 ~라면 ~해라"* 로 흐름을 나누는 문장 |
> | **불리언(bool)** | **참(`True`) / 거짓(`False`)** 두 가지뿐인 값 |
> | **비교 연산자** | 두 값을 비교해서 참/거짓을 만드는 기호 |
> | **`random`** | 무작위 숫자를 뽑는 파이썬의 도구 상자(모듈) |
> | **들여쓰기** | 줄 앞의 **빈칸 4칸**. 파이썬에서는 *"어디까지가 이 `if` 의 일인지"* 를 알려 주는 **문법** |

### 2-2. 비교 연산자 표

| 기호 | 뜻 | 예 | 결과 |
|:--:|:--|:--|:--:|
| `==` | **같다** | `5 == 5` | `True` |
| `!=` | **다르다** | `5 != 3` | `True` |
| `<` | 작다 | `3 < 5` | `True` |
| `>` | 크다 | `3 > 5` | `False` |
| `<=` | 작거나 같다 | `5 <= 5` | `True` |
| `>=` | 크거나 같다 | `4 >= 5` | `False` |

> ⚠️ **가장 많이 하는 실수**: `=` 와 `==` 를 헷갈리는 것!
> - `=` : **상자에 넣어라** (`age = 19`)
> - `==` : **같은지 물어봐라** (`age == 19`)

### 2-3. 🧪 체험 1 · 놀이터에서 비교해 보기

```python
>>> 5 > 3
True
>>> 5 == 6
False
>>> "사과" == "사과"
True
>>> age = 19
>>> age >= 20
False
```

### 2-4. `if / elif / else` 모양

```python
if 조건1:
    조건1이 참일 때 할 일
elif 조건2:
    조건1은 거짓이고, 조건2가 참일 때 할 일
else:
    위가 모두 거짓일 때 할 일
```

| 키워드 | 읽는 법 |
|:--|:--|
| `if` | **만약** … 라면 |
| `elif` (else if) | **그렇지 않고 만약** … 라면 |
| `else` | **그것도 아니면** |

> 🔑 **꼭 기억!** 조건 뒤에 **콜론(`:`)** 을 쓰고, 할 일은 **들여쓰기 4칸**!

> 📖 **JS와 비교** `if (조건) { … } else if (조건) { … } else { … }` → 파이썬은 **`(` `)` `{` `}` 대신 콜론(`:`)과 들여쓰기**를 써요.

| 줄 | 뜻 |
|:--|:--|
| `answer = random.randint(1, 20)` | 컴퓨터가 몰래 정답을 정해 `answer` 에 넣어요 |

| `elif guess < answer:` | **정답보다 작으면** → *더 큰 숫자*를 말해 줘야죠 |
| `else:` | 나머지 (= 정답보다 큼) |
| 들여쓰기 없는 마지막 `print(…)` | **항상** 실행돼요 |

> 📖 **JS와 비교** `if (조건) { … } else if (조건) { … } else { … }` → 파이썬은 **`{ }` 대신 콜론(`:`)과 들여쓰기**!

### 4-4. 🧪 에러 체험 (일부러 틀려 보기)

## 💪 도전 A · B (우수 학생용 중급 확장)

> 🧭 **도전도 두 레인으로!** ① 🅿️ **프롬프트 점검표**를 지켜 Antigravity에게 시키고 → ② 🅲 **코드 점검표**로 결과를 확인하세요. *(AI가 준 코드가 안 돌아가면 에러 메시지를 붙여 넣어 고치고, 마지막에 **내 말로 코드를 설명**해 보세요.)*
> ✍️ **프롬프트는 코드가 아니라 일상어로!** 아래 코드 조각은 *읽고 이해하기 위한 예시*예요. AI에게는 코드를 붙여 넣지 말고 **"무엇을 어떻게 되게 하고 싶은지"** 를 말로 설명해서 시켜 보세요.

### 💪 도전 A · "뜨겁다·차갑다 힌트"
*"더 크다/작다"* 말고, **정답과 얼마나 가까운지** 알려 주는 힌트를 만들어 보세요.

```python
diff = abs(guess - answer)       # abs() = 절댓값 (차이를 항상 양수로)
if diff == 0:
    print("정답!")
elif diff <= 2:
    print("🔥 아주 가까워요!")
elif diff <= 5:
    print("🙂 가까워요")
else:
    print("🥶 멀어요")
```
- `abs(-3)` → `3` (마이너스를 떼 줘요)

**목표**: ① `guess.py` 의 힌트를 **이 방식과 합쳐서**(크다/작다 + 뜨겁다/차갑다) 출력하기 ② 거리 기준(2, 5)을 **바꿔서** 난이도 조절해 보기 ③ `abs` 가 없으면 왜 문제인지 `guess=3, answer=10` 일 때를 손으로 계산해 설명하기

### 💪 도전 B · "난이도 선택 메뉴"

```python
level = input("난이도 (1=쉬움 2=보통 3=어려움): ")
```

## 📖 오늘의 용어 사전

| 용어 | 뜻 |
|:--|:--|
| 조건문 (`if`/`elif`/`else`) | 조건에 따라 할 일을 나누는 문장 |
| 참/거짓 (`True`/`False`) | 불리언 값 |
| 비교 연산자 | `==` `!=` `<` `>` `<=` `>=` |
| `=` / `==` | 상자에 넣기 / 같은지 묻기 |
| 들여쓰기 | 파이썬이 "같은 덩어리"를 알아보는 문법 (빈칸 4칸) |
| `import` / `random` | 도구 상자 가져오기 / 무작위 도구 |
| `abs()` | 절댓값 |
