## 2. 🧠 개념 파트 · 리스트와 딕셔너리 (50분)

### 2-1. 리스트 (줄 세운 상자들)

> 🧠 **비유: 서랍이 번호순으로 붙은 서랍장 / 줄 선 학생들**
> 학생 5명을 한 줄로 세워 놓고 *"세 번째 학생!"* 하고 부르죠? **리스트**는 여러 값을 **번호 순서대로** 한 줄에 담은 것이에요. (5주차 JS의 **배열**과 같은 것이에요!)

```text
 fruits = ["사과", "바나나", "포도"]

   번호:      0         1         2        ← 0부터 시작!
            ┌─────┐  ┌──────┐  ┌─────┐
   값:      │ 사과 │  │ 바나나 │  │ 포도 │
            └─────┘  └──────┘  └─────┘
```

> 📖 **새 용어 풀이**
> | 용어 | 쉬운 뜻 |
> |:--|:--|
> | **리스트(list)** | 순서 있는 값들의 목록. `[ ]` 로 감싸요 |
> | **인덱스(index)** | 리스트 속 **번호표** (0부터!) |
> | **요소(item)** | 리스트 안의 값 하나 |
> | **`len()`** | 리스트의 **개수**를 알려 주는 도구 |
> | **`append()`** | 리스트 **맨 뒤에 추가** |

### 🧪 체험 1 · 리스트 놀이터

```python
>>> fruits = ["사과", "바나나", "포도"]
>>> fruits[0]
'사과'
>>> fruits[2]
'포도'
>>> len(fruits)
3
>>> fruits.append("딸기")
>>> fruits
['사과', '바나나', '포도', '딸기']
>>> for fruit in fruits:
...     print(fruit, "맛있어요!")
...
사과 맛있어요!
바나나 맛있어요!
포도 맛있어요!
딸기 맛있어요!
```
> 🔍 `for fruit in fruits:` : 리스트의 값을 **하나씩 꺼내** `fruit` 상자에 넣으며 반복해요. (11주차 `range` 대신 **리스트를 직접** 돌려요!)

### 2-2. 딕셔너리 (이름표로 찾는 사전)

> 🧠 **비유: 국어사전 / 연락처**
> 사전에서 **단어(이름표)** 를 찾으면 **뜻(값)** 이 나오죠? **딕셔너리**는 `이름표: 값` 쌍을 모아 둔 **사전**이에요. (JS의 **객체**와 같은 것이에요!)

```text
 quiz = { "question": "대한민국의 수도는?", "answer": "서울" }

   이름표(key)     값(value)
  ┌──────────┐   ┌─────────────────────┐
  │ question │ → │ 대한민국의 수도는?     │
  │ answer   │ → │ 서울                 │
  └──────────┘   └─────────────────────┘
```

> 📖 **새 용어 풀이**
> | 용어 | 쉬운 뜻 |
> |:--|:--|
> | **딕셔너리(dict)** | `이름표: 값` 쌍의 사전. `{ }` 로 감싸요 |
> | **키(key)** | 값을 찾는 **이름표** |
> | **값(value)** | 이름표에 붙은 **내용** |

#### 🧪 체험 2 · 딕셔너리 놀이터

```python
>>> quiz = {"question": "대한민국의 수도는?", "answer": "서울"}
>>> quiz["question"]
'대한민국의 수도는?'
>>> quiz["answer"]
'서울'
>>> quiz["answer"] == "서울"
True
```
> ⚠️ 값을 꺼낼 때는 **대괄호 `[ ]` 안에 이름표를 따옴표로** 씁니다. 이름표를 틀리면 `KeyError` 가 나요.

#### 리스트 + 딕셔너리 = 문제은행

```text
 quiz_list = [   ← 리스트(줄)
    { "question": "대한민국의 수도는?", "answer": "서울" },    ← 0번 문제 (딕셔너리)
    { "question": "물은 섭씨 몇 도에서…", "answer": "100" },   ← 1번 문제
    ...
 ]
 quiz_list[0]["answer"]   →  "서울"
```
> 🧠 **비유: 카드 묶음** 문제 한 장 한 장이 **딕셔너리(앞면 질문 / 뒷면 정답)** 이고, 그 카드를 **한 줄로 쌓아 놓은 것이 리스트**예요.

> 🧭 **도전도 두 레인으로!** ① 🅿️ **프롬프트 점검표**를 지켜 Antigravity에게 시키고 → ② 🅲 **코드 점검표**로 결과를 확인하세요. *(AI가 준 코드가 안 돌아가면 에러 메시지를 붙여 넣어 고치고, 마지막에 **내 말로 코드를 설명**해 보세요.)*
> ✍️ **프롬프트는 코드가 아니라 일상어로!** 아래 코드 조각은 *읽고 이해하기 위한 예시*예요. AI에게는 코드를 붙여 넣지 말고 **"무엇을 어떻게 되게 하고 싶은지"** 를 말로 설명해서 시켜 보세요.

### 💪 도전 A · "문제 순서 섞기"
매번 같은 순서면 외워서 풀 수 있죠? **문제 순서를 무작위로** 섞어 보세요.

```python
import random

random.shuffle(quiz_list)      # 리스트의 순서를 무작위로 섞기
for quiz in quiz_list:
    ...
```
- `random.shuffle(리스트)` : 리스트 **자체를 섞어요** (새 리스트를 만드는 게 아니라 제자리에서 바뀌어요)

**목표**: ① `import random` 은 파일 **맨 위**에 쓰고, 게임 시작 전에 `shuffle` ② 3번 실행해서 **문제 순서가 달라지는지** 확인 ③ 섞은 뒤 **앞의 5문제만** 내기 (힌트: 리스트 자르기 `quiz_list[:5]`)

### 💪 도전 B · "과목별 문제은행 (딕셔너리 안의 리스트)"
퀴즈 **분야를 고르게** 하는 메뉴를 만들어 보세요. 딕셔너리의 값으로 **리스트**를 넣을 수 있어요!

```python
bank = {
    "과학": [{"question": "물의 끓는점은? (숫자만)", "answer": "100"}],
    "상식": [{"question": "대한민국의 수도는?", "answer": "서울"}],
}

subject = input("분야를 고르세요 (과학/상식): ")
for quiz in bank[subject]:
    print(quiz["question"])
```
```text
 bank = {
   "과학": [ 카드, 카드, … ],     ← 이름표(분야) → 값(문제 리스트)
   "상식": [ 카드, 카드, … ],
 }
 bank["과학"]  →  과학 문제 리스트
```
**목표**: ① 분야마다 문제를 **3개 이상** 만들기 ② 분야 이름을 **잘못 입력하면** `KeyError` 가 나는 걸 확인하고, `if subject in bank:` 로 **안내 메시지**를 출력해 막아 보기 ③ 분야를 고른 뒤 그 문제들로 게임 진행
