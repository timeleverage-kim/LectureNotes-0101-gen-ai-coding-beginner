## 2. 🧠 개념 파트 · 파일에 저장하기 (35분)

### 2-1. 변수에 담은 값은 "프로그램이 꺼지면 사라져요"

> 🧠 **비유: 칠판 vs 공책**
> 변수는 **칠판**과 같아요. 수업이 끝나면(프로그램이 끝나면) **지워져요.** **파일**은 **공책**이에요. 적어 두면 **껐다 켜도 남아 있어요.** 최고 점수처럼 *"나중에도 필요한 정보"* 는 공책(파일)에 적어야 해요.

```text
  프로그램 실행 중        프로그램 종료         다시 실행
   변수 (칠판) ✏️   ──▶   🧽 사라짐!
   파일 (공책) 📒   ──▶   📒 그대로 남음   ──▶   📒 읽어서 이어서!
```

> 📖 **새 용어 풀이**
> | 용어 | 쉬운 뜻 |
> |:--|:--|
> | **파일 입출력** | 파일에 **쓰고(저장)** 파일에서 **읽는(불러오기)** 것 |
> | **`open()`** | 파일을 **여는** 도구 |
> | **모드** | 파일을 어떻게 열지: `"r"`(읽기), `"w"`(쓰기, 처음부터 새로) |
> | **`with`** | 파일을 쓰고 나면 **자동으로 닫아 주는** 안전한 방법 |
> | **예외(exception)** | 프로그램 실행 중에 생긴 **문제 상황** (파일 없음 등) |
> | **`try / except`** | *"일단 해 보고, 문제가 생기면 이렇게 대처해"* |

### 2-2. 🧪 체험 1 · 파일에 쓰고 읽기

`write_read.py` 를 만들어 실행해 보세요.

```python
# 1. 파일에 쓰기 ("w" = write)
with open("memo.txt", "w", encoding="utf-8") as f:
    f.write("안녕, 파일!")

# 2. 파일에서 읽기 ("r" = read)
with open("memo.txt", "r", encoding="utf-8") as f:
    text = f.read()

print("읽어 온 글:", text)
```
실행하면 같은 폴더에 **`memo.txt` 파일이 생기고** 그 안에 `안녕, 파일!` 이 적혀 있어요. 직접 열어서 확인해 보세요!

| 코드 | 뜻 |
|:--|:--|
| `open("memo.txt", "w", encoding="utf-8")` | `memo.txt` 를 **쓰기 모드**로 열어요. `encoding="utf-8"` 은 **한글이 깨지지 않게** 하는 설정 |
| `as f` | 열린 파일을 `f` 라는 이름으로 부를게요 |
| `f.write("…")` | 파일에 **글자를 써요** |
| `f.read()` | 파일의 **내용을 전부 글자로** 읽어요 |
| `with … :` 의 들여쓰기 | 들여쓰기가 끝나면 **파일을 자동으로 닫아요** |

> ⚠️ 파일에는 **글자만** 저장할 수 있어요. 숫자를 저장하려면 `str(점수)` 로 글자로 바꾸고, 읽은 뒤 `int(글자)` 로 숫자로 되돌려요. (9주차의 `int`/`str` 이 여기서 또 쓰여요!)

> ⚠️ `"w"` 모드는 **기존 내용을 지우고** 처음부터 새로 써요. 조심!

## 3. 🧠 개념 파트 · try / except — 파일이 없어도 괜찮아요 (25분)

### 3-1. 문제 상황
처음 게임을 실행하면 **`best_score.txt` 파일이 아직 없죠?** 없는 파일을 읽으려 하면 프로그램이 **에러로 멈춰요.**

```text
FileNotFoundError: [Errno 2] No such file or directory: 'best_score.txt'
```

### 3-2. 해결: "일단 해 보고, 문제가 생기면 이렇게 해"

> 🧠 **비유: 안전망** 서커스 공중그네 아래의 **안전망**처럼, 떨어져도(에러가 나도) **다치지 않게** 받아 주는 장치예요.

```python
try:
    (일단 해 볼 일)
except FileNotFoundError:
    (파일이 없을 때 대신 할 일)
```
```text
   try 안의 코드 실행
     ├─ 문제 없음 ✅ → except 는 건너뜀
     └─ 문제 발생 ❌ → 즉시 except 로 이동 → 안내하고 계속 진행!
```

> 📖 **JS와 비교** `try { … } catch (error) { … }` → 파이썬은 `try:` / `except 에러종류:`.

> ⚠️ **`except` 뒤에 에러 종류를 적으세요.** 종류 없이 모든 에러를 삼키면 *진짜 버그*까지 숨겨져서 찾기 어려워져요.

### 5-3. 🅲 코드 읽기 — 기준 코드

**📄 quiz_game.py (14주차 완성본)**

```python
# quiz_game.py - 최고 점수를 파일에 저장하는 퀴즈 게임 (14주차 완성본)

SCORE_FILE = "best_score.txt"

quiz_list = [
    {"question": "대한민국의 수도는?", "answer": "서울"},
    {"question": "물은 섭씨 몇 도에서 끓을까요? (숫자만)", "answer": "100"},
    {"question": "파이썬(Python)이라는 이름은 어떤 동물에서 왔을까요?", "answer": "뱀"},
    {"question": "1 + 2 x 3 은?", "answer": "7"},
]


def is_correct(user_answer, answer):
    return user_answer.strip() == answer


def get_grade(score, total):
    if score == total:
        return "🏆 퀴즈 박사"
    elif score >= total / 2:
        return "👍 퀴즈 도전자"
    else:
        return "🌱 퀴즈 새싹"


def play(quizzes):
    score = 0
    for quiz in quizzes:
        user_answer = input(quiz["question"] + " ")
        if is_correct(user_answer, quiz["answer"]):
            print("⭕ 정답!")
            score = score + 1
        else:
            print("❌ 오답! 정답은", quiz["answer"])
    return score


def load_best_score():
    """저장된 최고 점수를 읽는다. 파일이 없으면 0점."""
    try:
        with open(SCORE_FILE, "r", encoding="utf-8") as f:
            return int(f.read())
    except (FileNotFoundError, ValueError):
        return 0


def save_best_score(score):
    """최고 점수를 파일에 적는다."""
    with open(SCORE_FILE, "w", encoding="utf-8") as f:
        f.write(str(score))


if __name__ == "__main__":
    print("=== 파이썬 퀴즈 ===")
    best = load_best_score()
    print("지금까지의 최고 점수:", best)

    my_score = play(quiz_list)
    print("맞힌 개수:", my_score, "/", len(quiz_list))
    print("나의 등급:", get_grade(my_score, len(quiz_list)))

    if my_score > best:
        save_best_score(my_score)
        print("🎉 최고 점수를 새로 썼어요!")
```
