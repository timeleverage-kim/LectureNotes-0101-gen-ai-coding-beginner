## 2. 🧠 개념 파트 · 파이썬이란? (30분)

### 2-1. 파이썬 = "읽기 쉬운 코딩 언어"

> 🧠 **비유: 영어 문장처럼 읽히는 레시피**
> 파이썬은 사람이 **글처럼 읽기 쉽게** 설계된 언어예요. AI, 데이터 분석, 자동화, 게임, 웹 서버까지 **거의 모든 분야**에서 쓰이는 *만능 접착제* 같은 언어입니다. 그래서 가장 인기 있는 첫 언어로 꼽혀요. (이름은 영국 코미디 쇼 *"Monty Python"* 에서 왔어요. 뱀 🐍 은 로고 그림일 뿐!)

> 📖 **새 용어 풀이**
> | 용어 | 쉬운 뜻 |
> |:--|:--|
> | **Python(파이썬)** | 읽기 쉬운 문법의 프로그래밍 언어 |
> | **터미널** | 글자로 명령하는 검은 창 (2주차에 배웠어요) |
> | **실행(run)** | 프로그램을 컴퓨터가 *"읽고 따라 하게"* 하는 것 |
> | **스크립트(script)** | 파이썬 코드를 적은 파일 (`.py`) |
> | **놀이터(REPL)** | 한 줄씩 입력하고 **바로 결과를 보는** 파이썬 대화창 |

### 2-2. 🧪 체험 1 · 파이썬 놀이터 (REPL)

터미널에서 `python` (Windows에서 안 되면 `py`, Mac은 `python3`)을 입력하면 **`>>>`** 표시가 나와요. 이게 **놀이터**입니다. 아래를 **한 줄씩** 입력해 보세요!

```python
>>> print("안녕, 파이썬!")
안녕, 파이썬!
>>> 2 + 3
5
>>> 7 / 2
3.5
>>> 7 // 2
3
>>> 7 % 2
1
>>> 2 ** 10
1024
>>> name = "하늘"
>>> "안녕하세요, " + name + "님!"
'안녕하세요, 하늘님!'
>>> exit()
```

| 연산 | 뜻 | 예 |
|:--|:--|:--|
| `+` `-` `*` | 더하기 · 빼기 · 곱하기 | `2 * 3` → `6` |
| `/` | 나누기 (소수 결과) | `7 / 2` → `3.5` |
| `//` | **몫** (나눗셈의 정수 부분) | `7 // 2` → `3` |
| `%` | **나머지** | `7 % 2` → `1` |
| `**` | 거듭제곱 | `2 ** 10` → `1024` |

> 🧠 **`//` 와 `%` 비유: 사탕 나눠 주기** 사탕 7개를 2명에게 똑같이 나누면 **한 명당 3개(`//`)** 씩 주고 **1개가 남죠(`%`)**.

### 라운드 2 🅿️ — `age.py` (나이 계산기)

**요구 정리표**

| 질문 | 나의 대답 |
|:--|:--|
| 파일 | week09 폴더의 `age.py` |
| 올해 | 2026 (맨 위에 따로 적어 두기) |
| 입력 | 이름(글자), 태어난 해(**정수로 바꿔서**) |
| 계산 | 나이 = 올해 − 태어난 해, 강아지 나이 = 나이 × 7 |
| 출력 | `하늘 님은 올해 19 살이에요.` / `강아지 나이로 바꾸면 133 살이래요! 🐶` |

> 🤖 **프롬프트 ② (age.py)**
> ```text
> week09 폴더에 파이썬 프로그램 파일(이름: age.py)을 만들어 줘. 초보자용으로 단순하게.
>
> 1. 맨 위에 "올해 = 2026" 이라는 값을 따로 적어 둬. (나중에 고치기 쉽게)
> 2. "=== 나이 계산기 ===" 를 보여 줘.
> 3. 이름과 태어난 해를 차례로 물어보고 기억해. 태어난 해는 계산할 수 있게 숫자로 바꿔서 기억해야 해.
> 4. 나이를 계산해 줘. (올해 - 태어난 해) 그리고 강아지 나이도 계산해 줘. (나이 × 7)
> 5. 아래처럼 보여 줘:
>    "하늘 님은 올해 19 살이에요."
>    "강아지 나이로 바꾸면 133 살이래요! 🐶"
>
> 지켜 줄 것: 반복과 함수는 쓰지 마. 줄마다 한국어 설명을 달아 줘. 실행은 내가 직접 할 거야.
> 먼저 계획을 보여 주고, 내가 확인하면 만들어 줘.
> ```

**점검표 ✅**: *"정수로 바꿔서(`int`)"* 를 적었나? / **입력 순서(이름 → 태어난 해)** 를 적었나? / **출력 문장 모양**을 적었나?

## 4. 🅲 코드 파트 · 실행해 보고 코드 읽기 (55분)

> 🧭 **파이썬은 "내가 직접 실행"해서 확인해요.** AI가 *"잘 돌아가요!"* 라고 해도, 내 눈으로 **출력**을 봐야 믿을 수 있어요.

### 4-1. 🅲 실행하기

터미널에서 폴더로 이동한 뒤 **실행**합니다.

```bash
cd ~/dev/my-portfolio/week09        # (Windows는 cd C:\dev\my-portfolio\week09)
python hello.py                     # Mac은 python3 hello.py
```

**예상 결과 vs 실제 결과**

| 실행 | 입력 | 예상 출력 | ✔ |
|:--|:--|:--|:--:|
| `python hello.py` | 이름: `하늘` | `만나서 반가워요, 하늘 님!` | ☐ |
| `python age.py` | `하늘`, `2007` | `하늘 님은 올해 19 살이에요.` / `강아지 나이로 바꾸면 133 살이래요! 🐶` | ☐ |
| `python age.py` | `하늘`, `2000` | `26 살` / 강아지 나이 `182 살` | ☐ |

> 🧮 **직접 계산해서 비교**: `2026 - 2007 = 19`, `19 × 7 = 133`. 예상 출력은 **내가 손으로 계산한 값**이에요. AI의 코드가 틀렸다면 숫자가 달라져요!

### 4-2. 🅲 코드 읽기 — 기준 코드

**📄 hello.py (기준)**

```python
# hello.py - 파이썬과의 첫 대화
print("안녕하세요! 파이썬과의 첫 대화예요.")
name = input("이름이 뭐예요? ")
print("만나서 반가워요,", name, "님!")
```

**📄 age.py (기준)**

```python
# age.py - 나이 계산기
this_year = 2026

print("=== 나이 계산기 ===")
name = input("이름을 입력하세요: ")
birth_year = int(input("태어난 해를 입력하세요 (예: 2007): "))

age = this_year - birth_year
dog_age = age * 7

print(name, "님은 올해", age, "살이에요.")
print("강아지 나이로 바꾸면", dog_age, "살이래요! 🐶")
```

> 📖 **새 용어 풀이**
> | 용어 | 쉬운 뜻 |
> |:--|:--|
> | **Python(파이썬)** | 읽기 쉬운 문법의 프로그래밍 언어 |
> | **실행(run)** | 프로그램을 컴퓨터가 읽고 따라 하게 하는 것 |
> | **`print` / `input`** | 출력(컴퓨터가 **말하기**) / 입력(컴퓨터가 **듣기**) |
> | **변수** | 값을 담는 **이름표 붙은 상자** |
> | **자료형** | 값의 종류: 글자(`str`) / 정수(`int`) / 소수(`float`) |
> | **주석 `#`** | 컴퓨터는 읽지 않는 **설명글** |

| 줄 | 뜻 |
|:--|:--|
| `print("…")` | 괄호 안의 글을 **화면에 출력** |
| `name = input("…")` | 질문을 보여 주고 **키보드 입력을 받아** `name` 에 넣어요 |
| `print("만나서 반가워요,", name, "님!")` | 쉼표로 여러 개를 **한 줄에** 출력, 사이에 **띄어쓰기가 자동으로** |
| `birth_year = int(input(…))` | 입력(글자)을 **정수로 바꿔서** 저장. *(안쪽 괄호부터: `input` → `int`)* |
| `age = this_year - birth_year` | **계산 결과**를 `age` 상자에 저장 |

```text
 입력(input) ─▶ 변수에 저장 ─▶ 처리(계산) ─▶ 출력(print)    ← 1주차의 "입력→처리→출력"!
```

> 📖 **JS와 비교** `console.log("안녕")` → `print("안녕")` / `let name = …` → `name = …` (`let` 도, 줄 끝 `;` 도 필요 없어요!)

> ⚠️ **`input()` 으로 받은 것은 무조건 "글자"** 예요. `"5" + "3" = "53"` (이어 붙이기), `5 + 3 = 8` (더하기). 계산하려면 `int()` 로 바꿔야 해요.

| 변환 함수 | 뜻 | 예 |
|:--|:--|:--|
| `int("2007")` | 글자 → **정수** | `2007` |
| `float("3.5")` | 글자 → **소수** | `3.5` |
| `str(2007)` | 숫자 → **글자** | `"2007"` |

**🅲 코드 점검표 (AI가 자주 하는 실수)**

| # | 점검 | ✔ |
|:--:|:--|:--:|
| 1 | 태어난 해를 **`int()` 로 바꿨나?** (안 바꾸면 `TypeError`) | ☐ |
| 2 | 올해(`2026`)가 **변수로 맨 위에** 있나? (코드 중간에 숫자가 흩어져 있지 않나?) | ☐ |
| 3 | **약속하지 않은 것**(`def`, `for`, `class`)이 끼어 있지 않나? | ☐ |
| 4 | **출력 문장**이 내가 말한 모양과 같나? | ☐ |

## 💪 도전 A · B (우수 학생용 중급 확장)

> 🧭 **도전도 두 레인으로!** ① 🅿️ **프롬프트 점검표**를 지켜 Antigravity에게 시키고 → ② 🅲 **코드 점검표**로 결과를 확인하세요. *(AI가 준 코드가 안 돌아가면 에러 메시지를 붙여 넣어 고치고, 마지막에 **내 말로 코드를 설명**해 보세요.)*
> ✍️ **프롬프트는 코드가 아니라 일상어로!** 아래 코드 조각은 *읽고 이해하기 위한 예시*예요. AI에게는 코드를 붙여 넣지 말고 **"무엇을 어떻게 되게 하고 싶은지"** 를 말로 설명해서 시켜 보세요.

### 💪 도전 A · "용돈 계산기" (`//` 와 `%` 활용)
한 달 용돈을 입력하면 **하루에 쓸 수 있는 돈**과 **남는 돈**을 알려 주는 프로그램을 만들어요.

```python
allowance = int(input("한 달 용돈(원): "))
per_day = allowance // 30
rest = allowance % 30
print("하루에", per_day, "원씩 쓰면 되고,", rest, "원이 남아요")
```
**목표**: ① 위 코드를 실행해 보고 `90000`, `100000` 을 입력해 결과를 **직접 계산한 값과 비교**하기 ② **한 주(7일)** 기준으로 바꿔서 `weekly.py` 만들기 ③ 용돈을 **5000원짜리 간식**으로 몇 번 사 먹을 수 있는지 추가 출력하기

### 💪 도전 B · "이름 마법사" (글자 다루기)

```python
name = input("이름: ")
print("글자 수:", len(name))
print("거꾸로:", name[::-1])
print("하트:", "💖" * len(name))
```

| 코드 | 뜻 |
|:--|:--|
| `len(name)` | 글자 **개수** |
| `name[::-1]` | 글자를 **거꾸로** 뒤집기 |
| `"💖" * 3` | 글자를 **3번 반복** (`💖💖💖`) |

**목표**: ① 내 이름과 친구 이름으로 실행해 보기 ② `name.upper()` (대문자로) / `name.lower()` (소문자로) 를 추가해 영어 이름으로 시험하기 ③ **"이름 별 피라미드"**: `print("*" * 1)`, `print("*" * 2)`, … 를 직접 써서 별 5줄 만들기 → *(이걸 한 줄로 줄이는 방법은 11주차에 나와요!)*
