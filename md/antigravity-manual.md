## 1. 구글 안티그래비티가 무엇인가요?

**구글 안티그래비티(Google Antigravity)**는 구글이 만든 **AI 에이전트 중심(Agent-First) 개발 플랫폼 및 통합 개발 환경(IDE)**입니다.

쉽게 말해, 내가 직접 모든 코드를 한 줄씩 외워서 치는 대신 **똑똑한 AI 조교(에이전트)와 대화하면서** 아이디어를 정리하고, 프로그램을 만들고, 오류를 고칠 수 있는 작업 공간입니다.

### 두 가지 화면의 차이점
안티그래비티를 설치하면 크게 두 가지 도구를 만나게 됩니다.

| 구분 | Antigravity 앱 (데스크톱 앱) | Antigravity IDE (코드 에디터) |
| :--- | :--- | :--- |
| **아이콘 특징** | 흰색 배경 아이콘 | 검은색 그리드 배경 아이콘 |
| **주요 역할** | AI 에이전트와 대화하고 여러 프로젝트를 관리하는 **메인 작업실** | VS Code처럼 코드를 직접 보며 수정할 수 있는 **코딩 전용 편집기** |
| **추천 상황** | 아이디어 구상, 과제 문서 정리, AI에게 앱 제작 맡기기 | 코딩 과제 코드 직접 확인, 세부 수정, 터미널 실행 |

> 💡 **신입생 팁:** 처음에는 **Antigravity 앱**으로 시작해서 AI와 대화하는 데 익숙해진 뒤, 전공 수업이나 코딩 과제를 할 때 **Antigravity IDE**를 함께 활용하면 가장 좋습니다!

## 2. 설치 전 준비사항 확인하기

설치를 시작하기 전에 내 노트북 사양과 계정을 먼저 확인해 주세요.

### ✅ 필수 준비물
1. **개인 구글 계정 (Gmail):** 별도 결제 없이 개인 Gmail 계정만으로 무료 스타터 할당량을 받아 시작할 수 있습니다.
2. **운영체제(OS) 최소 사양:**
   * **Windows:** Windows 10 (64-bit) 또는 Windows 11
   * **macOS:** macOS 13 (Ventura) 이상 *(Apple Silicon M1~M4 또는 Intel 칩)*
   * **Linux:** Ubuntu 20+, Debian 10+, Fedora 36+ 등 (`glibc >= 2.28`)

### 🔍 내 노트북 사양 확인하는 법
* **Windows:** 키보드에서 `윈도우 키(⊞) + R` → `msinfo32` 입력 후 엔터 → **시스템 종류** 확인 (`x64 기반 PC`가 대부분입니다).
* **macOS:** 화면 왼쪽 상단 **사과() 아이콘** → **이 Mac에 관하여** 클릭 → 칩 항목에 `Apple M1~M4`가 있으면 **Apple Silicon**, `Intel`이 적혀 있으면 **Intel**입니다.

## 3. 운영체제별 설치 방법

먼저 구글 안티그래비티 공식 다운로드 페이지에 접속합니다.
* **공식 다운로드 주소:** `https://antigravity.google/download`

### 🪟 Windows 사용자
1. 다운로드 페이지에서 **Windows** 항목의 내 PC에 맞는 파일(`x64` 또는 `ARM64`)을 클릭해 `.exe` 설치 파일을 받습니다.
2. 다운로드한 `.exe` 파일을 더블 클릭하여 실행하고 **다음(Next) → 설치(Install) → 완료(Finish)**를 차례대로 눌러줍니다.
3. *(선택)* PowerShell을 다룰 줄 안다면 아래 한 줄 명령어로도 설치할 수 있습니다.
   ```powershell
   winget install -e --id Google.Antigravity --accept-package-agreements --accept-source-agreements
   ```

### 🍎 macOS 사용자
1. 다운로드 페이지에서 **macOS** 항목의 내 맥북에 맞는 파일(`Apple Silicon` 또는 `Intel`)을 클릭해 `Antigravity.dmg` 파일을 받습니다.
2. `.dmg` 파일을 더블 클릭한 뒤, **Antigravity 아이콘을 `Applications(응용 프로그램)` 폴더로 드래그**합니다.
3. `Launchpad` 또는 `응용 프로그램` 폴더에서 실행합니다.

### 🐧 Linux 사용자
1. 다운로드 페이지에서 **Linux**용 `.tar.gz` 압축 파일을 다운로드합니다.
2. 터미널을 열고 아래 명령어로 압축을 푼 뒤 실행합니다.
   ```bash
   tar -xzf Antigravity.tar.gz
   ./Antigravity
   ```

## 4. 초기 설정 및 로그인 따라하기

### Step 1. 구글 계정으로 로그인
* **Continue with Google (Google로 계속하기)** ✅ 클릭 *(기업용 Business Account는 선택하지 않습니다)*
* 브라우저에서 개인 Gmail로 로그인한 뒤 **Antigravity 열기**를 클릭합니다.

### Step 2. 작업 유형 및 화면 테마 선택
* 코딩/프로그래밍 실습용: **Software Engineering** 추천
* 문서 작성, 리서치, 일반 교양 과제용: **Knowledge Work** 추천
* *(나중에 `Settings > General > Interface Layout`에서 언제든 변경 가능)*
* 화면 테마(Light / Dark) 선택 후 약관 동의 → 완료!

### Step 3. (코딩 과제용) Antigravity IDE 추가 설치 및 한글화
1. 앱 오른쪽 상단의 **`Install Antigravity IDE`** 버튼을 눌러 독립형 IDE를 설치합니다.
2. IDE 최초 설정 마법사: `Start fresh` → `Normal` → **`Review-driven development (recommended)`** ✅
3. **한글 메뉴로 바꾸기:** 왼쪽 **확장(Extensions)** 아이콘 클릭(`Ctrl + Shift + X` / Mac `Cmd + Shift + X`) → `korean` 검색 → **Korean Language Pack** 설치 → IDE 재시작!

## 5. 초보자가 꼭 알아야 할 핵심 개념 4가지

1. **프로젝트 (Project):** 과제나 만들고 싶은 앱 하나를 담아두는 **작업 폴더**입니다. 에이전트는 지정된 폴더 안에서만 작업해 안전합니다.
2. **에이전트 (Agent):** 내 한국어 지시를 이해하고 계획을 세워 코드 작성과 테스트를 대신해 주는 **AI 코딩 조교**입니다.
3. **아티팩트 (Artifact):** 에이전트가 만들어주는 **구현 계획서·작업 목록·결과 요약서(Walkthrough)**입니다. 문서에 직접 댓글을 달아 수정 요청을 할 수 있습니다.
4. **대화 모드 (Planning vs Fast):**
   * **Planning (계획 모드):** 복잡한 과제나 앱을 만들 때 먼저 계획을 세우고 내 승인을 받습니다. **(초보자 기본 추천!)**
   * **Fast (빠른 모드):** 간단한 오타 수정이나 짧은 질문에 바로 답을 얻고 싶을 때 사용합니다.

## 6. 실전! 첫 프로젝트 만들고 웹앱 완성하기

코딩을 몰라도 5분 만에 **"대학생 과제 & 시험 일정 관리 웹앱"**을 만들어 볼 수 있습니다.

1. 내 컴퓨터 `문서(Documents)` 폴더 안에 `my-first-project` 폴더를 새로 만듭니다.
2. 안티그래비티 왼쪽 메뉴의 **Projects**에서 **`+ Create New Project`** → **`New Project`**를 눌러 해당 폴더를 연결합니다.
3. 대화창 모드가 **`Planning`**인지 확인한 뒤, 아래 프롬프트를 복사해 전송합니다.

```text
대학교 신입생이 쓸 수 있는 심플한 '과제 및 시험 일정 관리 웹앱'을 HTML 파일 하나로 만들어줘.

포함되어야 할 기능:
1. 과목명, 과제 제목, 마감일, 중요도(상/중/하)를 입력해 추가하는 기능
2. 마감일이 가까운 순서대로 자동 정렬되는 목록
3. 완료 체크박스를 누르면 취소선이 그어지고 완료 탭으로 이동하는 기능
4. 대학생이 보기 편한 깔끔하고 밝은 파스텔 톤 디자인 (모바일에서도 잘 보이게)

작업을 시작하기 전에 먼저 구현 계획을 한국어로 알기 쉽게 설명해 주고, 내 승인을 받은 뒤 코드를 작성해 줘.
```

4. 에이전트가 보여준 **구현 계획(Artifact)**을 읽어보고 **승인(Approve)**을 누릅니다.
5. 완료되면 `my-first-project` 폴더 안의 `.html` 파일을 더블 클릭해 브라우저에서 확인하세요! 🎉

## 7. 안티그래비티 명령어 리스트 총정리 (필수 ~ 심화)

안티그래비티 채팅창이나 터미널에서 특수 기호(`@`, `/`)와 명령어를 쓰면 AI 에이전트를 훨씬 정확하고 똑똑하게 다룰 수 있습니다. 신입생이 꼭 알아두면 좋은 순서대로 정리했습니다.

### 7-1. 채팅창 핵심 입력 기호 (가장 자주 씀!)
| 기호 | 기능 설명 | 신입생 실전 활용 예시 |
| :--- | :--- | :--- |
| **`@파일명`** | 특정 파일이나 폴더를 콕 집어서 지시 | `@index.html 파일에서 글씨 크기만 키워줘` |
| **`/`** | 슬래시 명령어 목록 호출 | 채팅창에 `/`만 입력해도 쓸 수 있는 명령어 메뉴가 뜹니다 |
| **`+` 버튼** | 이미지, PDF, 에러 스크린샷 첨부 | 오류 화면을 캡처해 첨부하고 *"이 에러 고쳐줘"*라고 질문 |

### 7-2. 작업 계획 & 실행 슬래시(`/`) 명령어
| 명령어 | 별칭(Alias) | 기능 설명 | 언제 쓰면 좋을까요? |
| :--- | :--- | :--- | :--- |
| **`/planning`** | - | 계획 모드로 전환 (먼저 계획을 세우고 승인 후 실행) | 새 과제나 복잡한 웹앱을 처음부터 만들 때 **(초보자 추천)** |
| **`/fast`** | - | 빠른 모드로 전환 (계획 단계 생략하고 즉시 답변/수정) | 간단한 오타 수정, 짧은 개념 질문 등 빠르게 답을 얻을 때 |
| **`/grill-me`** | - | 작업 전 AI가 나에게 먼저 확인 질문을 던지며 기획 구체화 | 만들고 싶은 건 있는데 아이디어가 막연할 때 **(강력 추천!)** |
| **`/goal`** | - | 최종 목표를 지정해 에이전트가 끝까지 단계별로 완수 | 여러 단계가 필요한 기능을 끝까지 완성시키고 싶을 때 |
| **`/btw`** | - | 현재 진행 중인 큰 작업을 방해하지 않고 짧은 곁가지 질문 | 과제 진행 도중 *"잠깐, HTML 태그 뜻이 뭐야?"* 물어볼 때 |
| **`/browser`** | - | 크롬(Chrome) 브라우저를 연동해 화면을 직접 확인·테스트 | 내가 만든 웹사이트 화면이 깨지지 않았는지 점검할 때 |
| **`/schedule`** | - | 특정 프롬프트를 정해진 시간이나 주기로 예약 실행 | 매일 아침 일정 확인 등 반복 작업을 자동화할 때 |

### 7-3. 대화 및 작업 되돌리기(`/`) 명령어
| 명령어 | 별칭(Alias) | 기능 설명 | 언제 쓰면 좋을까요? |
| :--- | :--- | :--- | :--- |
| **`/clear`** | `/new` | 현재 대화를 비우고 완전히 새로운 대화 시작 | 다른 과목 과제로 넘어갈 때 (이전 기억이 섞이지 않게!) |
| **`/rewind`** | `/undo` | 대화를 바로 이전 메시지 시점으로 되돌리기 | 에이전트가 내 의도와 다르게 엉뚱한 방향으로 갔을 때 |
| **`/resume`** | `/switch` | 예전에 했던 과거 대화 목록을 보고 이어서 진행 | 어제 하던 코딩 과제를 오늘 다시 이어서 할 때 |
| **`/fork`** | `/branch` | 현재 대화를 복제해 새로운 갈래(실험용 대화) 생성 | 기존 코드는 안전하게 두고 다른 디자인을 시험해 보고 싶을 때 |
| **`/compact`** | - | 너무 길어진 대화 내용을 핵심만 요약해 메모리 확보 | 대화가 길어져서 에이전트 속도가 느려지거나 헷갈려 할 때 |
| **`/artifact`** | - | 에이전트가 만든 계획서·요약서(아티팩트) 다시 열기 | 아까 봤던 구현 계획서를 다시 확인하고 싶을 때 |
| **`/diff`** | - | 에이전트가 수정한 코드의 변경 내역(전/후 비교) 확인 | 어떤 줄이 바뀌었는지 한눈에 검토하고 싶을 때 |
| **`/copy`** | - | 에이전트의 마지막 답변을 클립보드에 바로 복사 | 결과물을 보고서나 노션에 붙여넣을 때 |

### 7-4. 설정 · 모델 · 사용량 확인(`/`) 명령어
| 명령어 | 별칭(Alias) | 기능 설명 | 신입생 팁 |
| :--- | :--- | :--- | :--- |
| **`/help`** | - | 사용 가능한 전체 명령어 및 단축키 도움말 표시 | 명령어가 기억나지 않을 때 언제든 입력! |
| **`/config`** | `/settings` | 테마, 권한, 샌드박스 등 환경 설정 화면 열기 | 안전 설정을 확인하거나 화면 테마를 바꿀 때 |
| **`/usage`** | `/quota` | 현재 내 무료/유료 할당량(사용량) 확인 | 무료 플랜 잔여 횟수가 궁금할 때 수시로 확인 |
| **`/context`** | - | 현재 대화에서 사용 중인 기억 용량(토큰) 시각화 | 대화가 너무 길어졌는지 체크할 때 |
| **`/model`** | - | 사용할 AI 모델 변경 | 속도가 빠른 모델과 고성능 모델 사이를 전환할 때 |
| **`/effort`** | - | AI의 추론 깊이(생각하는 정도) 조절 | 어려운 알고리즘 과제일 때 추론 깊이를 높여 활용 |
| **`/permissions`** | - | 파일 수정·터미널 실행 등 도구 승인 권한 관리 | 항상 확인받도록 안전하게 권한을 관리할 때 |
| **`/learn`** | - | 최근 성공한 작업 방식을 재사용 가능한 규칙/스킬로 저장 | 자주 쓰는 과제 스타일을 AI에게 기억시킬 때 |
| **`/agents`** | - | 실행 중인 서브에이전트 목록 및 상태 확인 | 여러 작업을 동시에 시켰을 때 진행 상황 체크 |
| **`/mcp`** | - | 외부 도구(MCP 서버) 연결 및 관리 | 노션, 깃허브 등 외부 서비스와 연동할 때 (심화) |
| **`/exit`** | `/quit` | 현재 세션 종료 | CLI 터미널 작업을 마칠 때 |

### 7-5. (전공생 · 심화) 터미널용 Antigravity CLI (`agy`) 명령어
데스크톱 앱 대신 검은색 터미널(PowerShell, macOS 터미널 등)에서 빠르게 안티그래비티를 쓰고 싶을 때는 `agy` 명령어를 사용합니다. *(세부 옵션은 버전에 따라 달라질 수 있으므로 `agy --help`로 확인하세요.)*

| 터미널 명령어 | 기능 설명 | 사용 예시 |
| :--- | :--- | :--- |
| **`agy`** | 현재 폴더에서 대화형 안티그래비티 세션 시작 | `agy` |
| **`agy -p "질문"`** | 대화창에 들어가지 않고 질문 하나만 던지고 바로 답 받기 | `agy -p "파이썬 리스트 정렬 방법 알려줘"` |
| **`agy -c`** (`--continue`) | 이 폴더에서 직전에 하던 대화 바로 이어가기 | `agy -c` |
| **`agy --model [모델명]`** | 특정 AI 모델을 지정해서 바로 실행 | `agy --model gemini-3.5-flash "코드 리뷰해줘"` |
| **`agy models`** | 현재 사용할 수 있는 AI 모델 목록 확인 | `agy models` |
| **`agy update`** | Antigravity CLI를 최신 버전으로 업데이트 | `agy update` |
| **`agy --help`** | 터미널에서 쓸 수 있는 모든 명령어 옵션 보기 | `agy --help` |

매번 *"한국어로 설명해줘"*, *"쉽게 설명해줘"*라고 말하기 귀찮다면, 설정의 Rules 메뉴 또는 전역 규칙 파일(`~/.gemini/GEMINI.md`)에 아래 내용을 저장해 두세요!

```markdown
- 모든 답변과 코드의 주석은 반드시 친절한 '한국어'로 작성해 줘.

- 새로운 프로그램이나 패키지를 설치하거나 파일을 삭제하기 전에는 반드시 먼저 허락을 구해 줘.
- 코드를 수정할 때는 내가 이해할 수 있도록 어떤 부분을 왜 바꿨는지 요약해서 알려 줘.
```

## 9. 초보자 필수 안전 수칙 4가지

> ⚠️ **1. 검토 정책은 항상 `Always Ask (Request Review)`로 유지하세요!**
> 설정(`Settings > Agent` 또는 `/permissions`)에서 검토 정책을 `Always Ask`로 두어야 에이전트가 코드를 바꾸기 전에 항상 확인을 받습니다.

> ⚠️ **2. 보안 설정에서 `Unrestricted` 모드는 절대 쓰지 마세요!**
> `Unrestricted` 모드는 모든 안전장치를 끄는 기능으로, 중요한 파일이 실수로 삭제될 위험이 있습니다. 초보자는 반드시 기본값인 **`Default`** 상태를 유지하세요.

> ⚠️ **3. 무료 플랜 사용량(Quota)을 수시로 확인하며 아껴 쓰세요!**
> `/usage` 명령어로 잔여 할당량을 확인할 수 있습니다. 짧은 잡담보다는 **원하는 요구사항을 목록으로 정리해서 한 번에 명확하게 요청**하는 것이 효율적입니다.

> ⚠️ **4. 과제 제출 전 반드시 직접 실행하고 이해하세요!**
> AI가 만든 코드도 오류가 있을 수 있습니다. 제출 전에 직접 실행해 보고, `/diff`로 바뀐 코드를 확인하며 *"이 코드 한 줄씩 설명해 줘"*라고 물어 내 실력으로 만드세요.

## 10. 자주 묻는 질문 (FAQ)

**Q1. 코딩을 정말 하나도 모르는데 써도 괜찮나요?**
> 네! 구글 안티그래비티는 한국어로 대화하며 결과물을 만들 수 있게 설계되었습니다. 특히 `/grill-me` 명령어를 쓰면 AI가 친절하게 질문하며 방향을 잡아주어 입문자에게 최고입니다.

**Q2. 무료로 계속 쓸 수 있나요?**
> 개인 Gmail 계정으로 로그인하면 무료 스타터 할당량이 제공되어 대학생 과제나 연습용으로 충분히 시작할 수 있습니다. 사용량이 궁금할 때는 채팅창에 `/usage`를 입력해 보세요.

**Q3. 에이전트가 엉뚱한 코드를 짜버렸어요! 어떡하죠?**
> 채팅창에 **`/rewind`**를 입력해 이전 시점으로 되돌리거나, IDE에서 `Ctrl + Z`(Mac `Cmd + Z`)를 누르세요. 중요한 과제는 작업 전 폴더를 복사해 백업해 두는 습관을 들이면 더욱 안전합니다.

**Q4. 명령어가 너무 많아서 다 외워야 하나요?**
> 절대 외울 필요 없습니다! 채팅창에 슬래시(**`/`**)만 입력하면 자동완성 목록이 나타나고, 언제든 **`/help`**를 치면 도움말을 볼 수 있습니다. 처음에는 `@파일명`, `/planning`, `/grill-me`, `/rewind`, `/clear` 딱 5가지만 기억해도 충분합니다!
