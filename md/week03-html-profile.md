## 2. 🧠 개념 파트 · HTML이란? (30분)

### 2-1. HTML = 웹페이지의 "뼈대와 내용"

> 🧠 **비유: 책의 목차와 본문**
> 책에는 **큰 제목**, **본문 글**, **그림**, **목록**이 있죠? 웹페이지도 마찬가지예요. HTML은 *"여기는 제목, 여기는 본문, 여기는 사진"* 이라고 **이름표를 붙여서** 컴퓨터에게 알려 주는 언어입니다.

> 📖 **새 용어 풀이**
> | 용어 | 쉬운 뜻 |
> |:--|:--|
> | **HTML** | 웹페이지의 내용과 구조를 적는 언어. (HyperText Markup Language) |
> | **태그(tag)** | 내용에 붙이는 **이름표**. `<h1>`처럼 `<` `>` 로 감싸요 |
> | **요소(element)** | 시작 태그 + 내용 + 끝 태그를 합친 한 덩어리 |
> | **속성(attribute)** | 태그에 붙이는 **추가 설명** (`src="me.svg"`) |
> | **브라우저** | 웹페이지를 보여 주는 프로그램 (크롬, 엣지 등) |

### 2-2. 태그는 "여닫는 상자"

```text
   시작 태그           내용              끝 태그
 ┌──────────┐   ┌──────────────┐   ┌──────────┐
   <h1>         안녕하세요!         </h1>
 └──────────┘   └──────────────┘   └──────────┘
 └────────────────────────────────────────────┘
                   요소 (한 덩어리)
```

- **끝 태그**는 시작 태그 앞에 **`/`(슬래시)** 가 붙어요: `<h1>` 으로 열고 `</h1>` 으로 닫습니다.
- 마치 **상자를 열고 닫는 것**처럼, 열었으면 꼭 닫아 줘야 해요.

### 2-3. 오늘 만날 태그 모아 보기

| 태그 | 이름표의 뜻 | 쓰임 |
|:--|:--|:--|
| `<h1>` ~ `<h6>` | **h**eading (제목) | `h1`이 가장 큰 제목, 숫자가 커질수록 작은 제목 |
| `<p>` | **p**aragraph (문단) | 일반 글 한 덩어리 |
| `<strong>` | 강조 | **굵은 글씨** |
| `<ul>` + `<li>` | **u**nordered **l**ist / **l**ist **i**tem | 점(•) 목록 |
| `<ol>` + `<li>` | **o**rdered **l**ist | 번호(1, 2, 3) 목록 |
| `<img>` | **im**a**g**e (그림) | 사진 넣기 (끝 태그 없음!) |
| `<a>` | **a**nchor (닻·링크) | 누르면 이동하는 링크 |

### 2-4. 모든 HTML 문서의 기본 틀

```html
<!DOCTYPE html>          <!-- "이건 HTML 문서예요" 라는 선언 -->
<html lang="ko">         <!-- 문서 전체. 한국어 -->
  <head>                 <!-- 머리: 화면에는 안 보이는 정보 -->
    <meta charset="UTF-8" />   <!-- 한글이 안 깨지게 -->
    <title>나의 소개 페이지</title>   <!-- 브라우저 탭에 뜨는 이름 -->
  </head>
  <body>                 <!-- 몸: 화면에 보이는 모든 것 -->
    ...여기에 내용...
  </body>
</html>
```

```text
 <html>
  ├─ <head>  (머리)  → 탭 이름, 글자 설정 같은 "설정"
  └─ <body>  (몸)    → 눈에 보이는 제목, 글, 사진...
```

> 🧠 **비유: 사람의 몸** 머리(`head`)에는 *이름표·설정*이 있고, 몸(`body`)이 *화면에 보이는 부분*이에요. 오늘 작업은 거의 `<body>` 안에서 합니다.

## 4. 🅲 코드 파트 · 만들어진 페이지 확인하기 (50분)

> 🧭 이제부터는 **AI가 만든 결과를 내가 확인하는 시간**이에요. 순서는 **파일 확인 → 실행(눈) → 코드 읽기 → 고치기**!

### 4-1. 🅲 파일 확인
Antigravity 왼쪽 **파일 탐색기**에서 `week03` 안을 보세요.

| 확인 | ✔ |
|:--|:--:|
| `index.html` 과 `me.svg` **두 파일만** 있나요? (엉뚱한 `style.css` 등이 생겼다면 → AI가 약속을 어긴 거예요) | ☐ |
| 파일 이름의 **철자·확장자**가 맞나요? | ☐ |

### 4-2. 🅲 실행해서 동작 확인 (눈으로!)
`index.html` 을 **더블클릭**해 크롬으로 열고 **동작 점검표**를 확인하세요.

| # | 확인할 것 | 결과 |
|:--:|:--|:--:|
| 1 | 큰 제목에 **내 이름**이 보인다 | ☐ |
| 2 | 소개글에서 "첫 번째 웹사이트"만 **굵게** 보인다 | ☐ |
| 3 | **그림**(웃는 얼굴)이 보인다 | ☐ |
| 4 | 점(•) 목록 **3개**가 보인다 | ☐ |
| 5 | 번호(1, 2, 3) 목록 **3개**가 보인다 | ☐ |
| 6 | 링크를 누르면 **새 탭**에 구글이 열린다 | ☐ |
| 7 | 한글이 **깨지지 않는다** | ☐ |

> 🔎 **안 되는 항목이 있나요?** 그건 *"AI가 내 요구를 빠뜨렸거나 잘못 만들었다"* 는 뜻이에요. **4-5 고쳐 달라고 하기**로 가세요.

### 4-3. 🅲 코드 읽기 — 기준 코드와 비교하기

내 AI가 만든 코드가 아래 **기준 코드**와 **똑같을 필요는 없어요.** 같은 일을 하는지 **읽어서** 확인하세요. (이 코드는 직접 만들어 확인한 기준입니다.)

```html
<!DOCTYPE html>
<html lang="ko">
  <head>
    <meta charset="UTF-8" />
    <title>나의 소개 페이지</title>
  </head>
  <body>
    <h1>안녕하세요, 저는 하늘입니다!</h1>

    <img src="me.svg" alt="내 얼굴 그림" width="150" />

    <p>컴퓨터공학과 1학년이에요. 이 페이지는 제가 직접 만든 <strong>첫 번째 웹사이트</strong>입니다.</p>

    <h2>내가 좋아하는 것</h2>
    <ul>
      <li>게임</li>
      <li>음악</li>
      <li>사진 찍기</li>
    </ul>

    <h2>이번 학기 목표</h2>
    <ol>
      <li>코딩이 무섭지 않게 되기</li>
      <li>내 웹사이트 인터넷에 공개하기</li>
      <li>파이썬으로 작은 게임 만들기</li>
    </ol>

    <h2>가 보고 싶은 곳</h2>
    <p><a href="https://www.google.com" target="_blank">구글 열어 보기</a></p>
  </body>
</html>
```

**① 구조 읽기 — "어느 칸에 무엇이 있나?"**

| 확인할 것 | 어디를 보나 | ✔ |
|:--|:--|:--:|
| 맨 위 선언 | 첫 줄 `<!DOCTYPE html>` | ☐ |
| 한국어 문서 | `<html lang="ko">` | ☐ |
| 한글 안 깨짐 설정 | `<meta charset="UTF-8" />` | ☐ |
| 탭 이름 | `<title>` | ☐ |
| 눈에 보이는 내용 | **`<body>` 안**에만 있는가? | ☐ |

**② 짝 맞추기 — "여는 태그와 닫는 태그"**
> 🎯 눈에 띄는 태그 3개를 골라 **여는 태그 ↔ 닫는 태그**를 연필로 이어 보세요. (예: `<ul>` … `</ul>`, 그 사이에 `<li>`가 3개!)

| 태그 | 닫는 태그가 있나? |
|:--|:--|
| `<h1>` `<p>` `<strong>` `<li>` `<ul>` `<ol>` `<a>` | ✅ 있다 (`</태그>`) |
| `<img>` | ❌ 없다 (내용이 없는 태그, 끝을 ` />` 로) |

**③ 속성 읽기**

| 코드 | 뜻 |
|:--|:--|
| `src="me.svg"` | **s**ou**rc**e — 그림 파일의 이름(주소) |
| `alt="내 얼굴 그림"` | 그림을 못 볼 때 보여 줄 설명 |
| `width="150"` | 가로 크기 150**픽셀(px)** |
| `href="https://…"` | 이동할 주소 |
| `target="_blank"` | **새 탭**에서 열기 |

> 📖 **픽셀(px)**: 화면을 이루는 작은 점 하나의 크기 단위. 150px = 점 150개만큼의 길이.

**④ 🅲 코드 점검표 (AI가 자주 하는 실수 찾기)**

| # | 점검 | ✔ |
|:--:|:--|:--:|
| 1 | `<style>` 이나 `style="…"` 처럼 **CSS가 몰래 섞여 있지** 않나? (우리는 HTML만 쓰기로 했어요) | ☐ |
| 2 | `<script>` 가 **없나?** | ☐ |
| 3 | `<img>` 에 `alt` 가 **있나?** | ☐ |
| 4 | 그림 `src` 의 파일 이름이 **실제 파일명과 같나?** (`me.svg`) | ☐ |
| 5 | `<h1>` 이 **하나뿐**인가? | ☐ |

### 4-4. 🧪 일부러 틀려 보기 (오류가 무섭지 않아져요)
1. `</h1>` 의 `/` 를 **지우고** 새로고침 → 뒤의 글까지 전부 큰 제목이 되죠? *"닫는 걸 잊으면 이렇게 돼!"* 를 눈으로 확인하고 **되돌리세요.**
2. `src="me.svg"` 를 `src="me.png"` 로 **틀리게** 바꿔 보세요 → 그림이 사라지고 `alt` 글자가 보이죠? 되돌리세요.

> 💡 **작업 리듬**: ✏️ 고치기 → 💾 저장(`Ctrl+S`) → 🔄 새로고침(`F5`) → 👀 확인

### 4-5. 🅿️→🅲 고쳐 달라고 하고, 다시 확인하기

점검에서 문제가 나왔다면 **이렇게 말해요.** (문제를 *구체적으로* 말할수록 좋아요!)

| 문제 | 🅿️ 고쳐 달라는 프롬프트 | 🅲 다시 확인 |
|:--|:--|:--|
| CSS가 섞여 있음 | `꾸미기 관련 부분이 섞여 있어. 꾸미기 부분을 모두 없애 줘. 내용은 바꾸지 마.` | 동작 점검표 + 코드 점검표 1번 |
| 그림이 안 보임 | `그림이 안 보여. 같은 폴더의 me.svg 파일을 가리키게 그림 부분만 고쳐 줘. 다른 곳은 건드리지 마.` | 그림이 보이나? |
| 목록이 3개가 아님 | `좋아하는 것 목록이 3개가 아니야. 게임, 음악, 사진 찍기 3개만 남겨 줘.` | 목록 개수 |

> 🔁 **되돌리기**: 마음에 안 들게 바뀌었다면 `git restore week03/index.html` (아직 저장하기 전이라면!) 또는 에디터에서 `Ctrl+Z`.

### 💪 도전 A · "표로 만든 시간표"
이번 학기 **시간표**를 표로 만들어 보세요. 새 태그가 필요해요.

| 태그 | 뜻 |
|:--|:--|
| `<table>` | 표 전체 |
| `<tr>` | 표의 한 **줄** (table row) |
| `<th>` | **제목 칸** (table heading) |
| `<td>` | 일반 **칸** (table data) |

```html
<table border="1">
  <tr>
    <th>요일</th><th>1교시</th><th>2교시</th>
  </tr>
  <tr>
    <td>월</td><td>웹프로그래밍</td><td>파이썬</td>
  </tr>
</table>
```
**목표**: 월~금 5줄 시간표를 완성하세요. (힌트: `<tr>` 줄을 복사해서 붙이면 편해요.)

### 💪 도전 B · "나의 순위 페이지 + 페이지 이동"
1. **좋아하는 음식 TOP 3**를 `<ol>` 로 만들어 `top3.html` 이라는 **두 번째 페이지**에 넣으세요.

> 💭 생각해 보기: `href="top3.html"` 처럼 **짧게** 쓴 주소와 `href="https://www.google.com"` 처럼 **길게** 쓴 주소는 무엇이 다를까요? (힌트: 같은 폴더 안의 파일 vs 인터넷 저편의 사이트)
