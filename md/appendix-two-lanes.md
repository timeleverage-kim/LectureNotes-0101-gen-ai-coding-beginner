# 부록 · 한 장으로 보는 "두 레인" 카드 (Antigravity 작업 루프)

> 인쇄해서 책상에 붙여 두고 쓰세요. 모든 주차의 실습은 이 순서로 진행합니다.

## 🔁 표준 작업 루프

```text
 🅿️ 프롬프트 파트 (AI에게 시키기)                🅲 코드 파트 (결과 확인하기)
 ① 요구 정리 (표)                               ⑥ 파일 확인 (엉뚱한 파일이 생기지 않았나?)
 ② 프롬프트 작성 (역할·목표·조건·출력)           ⑦ 실행·동작 점검표 (예상 결과를 먼저 적고!)
 ③ 🅿️ 프롬프트 점검표 ✅                        ⑧ 코드 읽기 (기준 코드와 비교, 모르는 줄은 질문)
 ④ 에이전트에 보내기 (Planning 모드)             ⑨ 🅲 코드 점검표 ✅ + git diff
 ⑤ 계획서(아티팩트) 읽고 승인/수정               ⑩ 문제 → 범위를 좁혀 고쳐 달라기 / 되돌리기 → 저장(커밋)
```

## 🅿️ 프롬프트 점검표 (보내기 전)

| # | 점검 | ✔ |
|:--:|:--|:--:|
| 1 | **역할**이 있나요? (누구처럼 대답할지) | ☐ |
| 2 | **목표**가 한 문장으로 분명한가요? | ☐ |
| 3 | **파일 위치·이름, 버튼 이름표, 색 코드** 같은 *정확히 맞아야 하는 약속만* 적었나요? (나머지는 **코드 없이 일상어**로) | ☐ |
| 4 | **건드리지 말 것**(범위)을 적었나요? (*"CSS만"*, *"이 함수만"*) | ☐ |
| 5 | **"먼저 계획을 보여 줘"** 를 넣었나요? | ☐ |
| 6 | **누가 실행할지**(*"실행은 내가 직접"*)를 적었나요? (파이썬 주차) | ☐ |
| 7 | 개인정보·비밀번호가 **없나요?** | ☐ |

## 🅲 코드 점검표 (받은 뒤)

| # | 점검 | ✔ |
|:--:|:--|:--:|
| 1 | **계획서**와 실제 만들어진 파일이 같은가? (약속 밖의 파일·수정은 없나?) | ☐ |
| 2 | **실행**해 봤나요? (브라우저 / 터미널) | ☐ |
| 3 | **예상 결과표**와 실제 결과가 같은가? (경계값, 일부러 틀린 입력 포함) | ☐ |
| 4 | **Console / 에러 메시지**가 없나요? 있다면 **줄 번호와 이유**를 읽었나요? | ☐ |
| 5 | 코드를 **한 번은 읽었나요?** (모르는 줄은 AI에게 *"파일은 수정하지 말고 설명만"* 요청) | ☐ |
| 6 | `git diff` 로 **바뀐 곳만** 확인했나요? | ☐ |
| 7 | 마음에 들면 **저장(커밋)**, 아니면 **되돌리기**(`git restore 파일`, `Ctrl+Z`) | ☐ |

## 🧩 프롬프트 템플릿 모음

**① 새로 만들기**
```text
너는 (역할)이야.
(폴더/파일 이름)에 (무엇)을 만들어 줘.
보이는 모습: (화면이나 출력이 어떻게 보이면 좋은지, 말로)
눌렀을 때/실행했을 때 일어날 일: (말로)
지켜 줄 약속: (파일 이름, 버튼 이름표, 색 코드처럼 꼭 맞아야 하는 것만)
하지 말 것: (꾸미기, 반복, 함수 등 이번에 쓰지 않을 것)
먼저 계획을 보여 주고, 내가 확인하면 만들어 줘. (파이썬이면) 실행은 내가 직접 할 거야.
```

**② 범위를 좁혀 고치기**
```text
(파일 이름)의 (이 부분)만 고쳐 줘. 다른 부분은 절대 바꾸지 마.
문제: (무엇이 어떻게 이상한지 일상어로 구체적으로)
```

> ✍️ 프롬프트에는 **코드를 붙여 넣지 않아요.** 에러 메시지처럼 *컴퓨터가 준 글*만 그대로 붙여 넣어요.

**③ 에러를 붙여 넣어 원인 묻기**
```text
이런 에러가 났어. 무슨 뜻이고 어떻게 고쳐야 해? 초보자 눈높이로 설명해 줘.
(에러 메시지 전체)
파일은 아직 고치지 말고 설명만 해 줘.
```

**④ 코드 설명 부탁하기 (🅲 이해 확인)**
```text
(파일 이름)을 한 줄씩 초등학생도 이해할 수 있게 비유를 써서 설명해 줘. 파일은 수정하지 마.
```

## ⚙️ Antigravity 설정 체크 (처음 한 번)

| 설정 | 선택 | 이유 |
|:--|:--|:--|
| 터미널 명령 실행 | **실행 전에 물어보기** | 명령을 **내가 읽고 허락** |
| 검토 방식 | **계획·변경을 먼저 확인받기** | AI가 몰래 많이 바꾸지 못하게 |
| 작업 모드 | **Planning** (계획 먼저) | *계획 → 승인 → 만들기* |

> ⚠️ *"항상 자동 실행"* 은 켜지 마세요. 메뉴 이름은 버전마다 다를 수 있으니 **같은 뜻**의 항목을 찾으세요.
