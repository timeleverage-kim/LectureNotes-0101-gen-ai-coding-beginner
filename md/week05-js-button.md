## 2. 🧠 개념 파트 · JavaScript란? (40분)

### 2-1. JS = 웹페이지의 "움직임(근육)"

> 🧠 **비유: 사람의 몸**
> HTML은 **뼈대**, CSS는 **옷**, JavaScript는 **근육**이에요. 근육이 있어야 *"손을 들면 인사한다"* 같은 **행동**을 할 수 있죠. JS가 들어가면 웹페이지가 *"보기만 하는 그림"* 에서 *"반응하는 프로그램"* 이 돼요.

```text
  👆 사용자가 버튼을 누른다 (이벤트)
         ↓
  💪 JS가 "할 일"을 실행한다 (함수)
         ↓
  🖥️ 화면의 글자·색이 바뀐다
```

> ⚠️ **이름이 비슷하지만 JavaScript는 Java와 전혀 다른 언어예요!** (인도 ≠ 인도네시아 정도의 차이 😄)

> 📖 **새 용어 풀이**
> | 용어 | 쉬운 뜻 |
> |:--|:--|
> | **JavaScript(JS)** | 웹페이지에 **움직임**을 주는 프로그래밍 언어 |
> | **변수(variable)** | 값을 담아 두는 **이름 붙은 상자** |
> | **함수(function)** | 이름을 붙인 **할 일 묶음** (레시피 한 장) |
> | **이벤트(event)** | 클릭, 키 입력처럼 **사용자가 한 행동** |
> | **문자열(string)** | 따옴표로 감싼 글자 (`"안녕"`) |
> | **콘솔(console)** | 개발자용 **메모·에러 창** |

### 2-2. 🧪 체험 1 · 콘솔에서 JS 맛보기

JS를 **한 줄씩 바로 실행**해 볼 수 있는 곳이 있어요!

1. 크롬에서 아무 페이지나 열고 **`F12`** → **Console(콘솔)** 탭을 클릭합니다.
2. 아래를 **한 줄씩** 입력하고 Enter!

```javascript
2 + 3
"안녕" + "하세요"
let name = "하늘"
name
"반가워요, " + name + "님!"
alert("안녕하세요!")
```

| 입력 | 결과 | 배운 점 |
|:--|:--|:--|
| `2 + 3` | `5` | 계산기처럼 쓸 수 있어요 |
| `"안녕" + "하세요"` | `"안녕하세요"` | 글자도 `+` 로 **이어 붙여요** |
| `let name = "하늘"` | (아무 출력 없음) | **변수 상자**에 값을 넣었어요 |
| `name` | `"하늘"` | 상자 안의 값을 꺼내 볼 수 있어요 |
| `alert("…")` | 팝업창! | 화면에 메시지를 띄워요 |

### 2-3. 변수 = 이름표 붙은 상자

```text
  let count = 0;

   ┌───────┐
   │   0   │  ← 값 (상자 안 내용물)
   └───────┘
     count    ← 이름 (상자에 붙인 이름표)

  count = count + 1;     → 상자 속 값을 꺼내 1을 더해서 다시 넣기

   ┌───────┐
   │   1   │
   └───────┘
     count
```

| 키워드 | 뜻 |
|:--|:--|
| `let` | *"바뀔 수 있는 상자를 만들게요"* |
| `const` | *"한 번 담으면 안 바뀌는 상자를 만들게요"* |
| `=` | 수학의 같다(=)가 아니라 **"오른쪽 값을 왼쪽 상자에 넣어라"** |

### 2-4. 함수 = 이름 붙은 레시피

```javascript
function sayHello() {
  alert("안녕하세요!");
}

sayHello();     // ← 이름을 부르면 레시피가 실행돼요 (호출)
```

- **정의**: 레시피를 *"적어 두는 것"* (`function sayHello() { … }`) — 적기만 해서는 아무 일도 안 일어나요.
- **호출**: 이름 뒤에 `()` 를 붙여 *"지금 실행해!"* (`sayHello();`)

### 2-5. 이벤트 = "이런 일이 생기면, 이걸 해 줘"

```text
  버튼.addEventListener("click", 할 일)
        ↑                ↑          ↑
   누구에게?        어떤 일이?     그러면 뭘 할까?
   (버튼)          (클릭)        (함수)
```

> 🧠 **비유: 초인종** 초인종(버튼)을 **누르면(click)** 집 안에서 *"딩동!" 소리가 나는* 것과 같아요. *"누르면 → 이렇게 해라"* 라고 **미리 약속**해 두는 거예요.

### 라운드 1 🅿️ — 버튼 만들기 (HTML·CSS)

**Step 1. 요구 정리표**

| 넣을 것 | 화면에 보이는 모습 | 이름표 (꼭 지키기!) |
|:--|:--|:--|
| 인사 버튼 | "👋 인사 받기" 버튼 | `hello-button` |
| 인사 글 상자 | "버튼을 눌러 보세요!" 글 | `message` |
| 배경색 버튼 | "🎨 배경색 바꾸기" 버튼 | `color-button` |
| 위치 | "가 보고 싶은 곳" 제목 **바로 위**, "인사 받기" 작은 제목 아래 | |
| 버튼 모양 | 주황색 배경, 흰 글자, 둥글게, 마우스를 올리면 더 진한 주황, 마우스 커서는 손가락 모양 | |

> 📖 **`id` 란?** `class` 가 *"여러 요소가 같이 쓰는 별명"* 이라면 `id` 는 **딱 한 요소만 가진 주민번호** 같은 이름표예요. JS가 *"저 버튼!"* 하고 **정확히 찾아낼 때** 써요.

**Step 2. 프롬프트 작성**

> 🤖 **프롬프트 ① (버튼 HTML·CSS)**
> ```text
> 너는 코딩을 처음 가르치는 친절한 선생님이야.
> week05 폴더의 웹페이지(index.html)에서 "가 보고 싶은 곳" 작은 제목 바로 위에 아래 내용을 추가해 줘. 기존 내용은 바꾸지 마.
>
> - 작은 제목: "인사 받기"
> - 버튼: "👋 인사 받기" (이름표: hello-button)
> - 안내 글: "버튼을 눌러 보세요!" (이름표: message)
> - 버튼: "🎨 배경색 바꾸기" (이름표: color-button)
>
> 그리고 꾸미기 파일(style.css) 맨 아래에 버튼 모양도 추가해 줘:
> 주황색 배경(#ff922b), 흰 글자, 테두리 없음, 안쪽 여백 넉넉하게, 모서리 둥글게,
> 마우스를 올리면 더 진한 주황(#f76707)으로, 마우스 커서는 손가락 모양으로.
>
> 지켜 줄 것: 이름표(hello-button, message, color-button)는 위에 적은 그대로 정확히 써 줘.
> 버튼이 움직이게 하는 프로그램(JavaScript)은 아직 만들지 마.
> 먼저 계획을 보여 주고, 내가 확인하면 만들어 줘.
> ```

**Step 3. 프롬프트 점검표 ✅**

| # | 점검 | ✔ |
|:--:|:--|:--:|
| 1 | **버튼·글 상자의 이름표 3개**를 정확히 적었나요? | ☐ |
| 2 | **"JavaScript는 아직 만들지 마"** 를 적었나요? (한 번에 하나씩!) | ☐ |
| 3 | **넣을 위치**와 **바꾸지 말 것**을 적었나요? | ☐ |
| 4 | **"먼저 계획을"** 이 있나요? | ☐ |

**Step 4. 보내고 계획서 읽기**: 계획서에 **이름표 3개가 정확히** 있고 `app.js` 같은 움직임 파일이 **끼어 있지 않은지** 확인한 뒤 승인합니다.

### 라운드 2 🅿️ — 인사 버튼에 JS 연결하기

**요구 정리표**

| 질문 | 나의 대답 |
|:--|:--|
| 파일 | week05 폴더의 `app.js` (새 파일). 웹페이지 **맨 아래(끝나기 바로 앞)** 에서 이 파일을 불러오게 하기 |

| 규칙 | 설명(주석)은 한국어로, 이름은 쉬운 영어 단어로 |

> 🤖 **프롬프트 ② (인사 버튼 JS)**
> ```text
> week05 폴더에 움직임을 담당할 파일(이름: app.js)을 만들고, 웹페이지 파일(index.html)의 맨 아래(몸 부분이 끝나기 바로 앞)에 이 파일을 불러오는 줄을 추가해 줘.
>
> app.js 가 할 일:
> 1. 인사 횟수를 기억하는 값을 하나 만들어. 처음에는 0이야.
> 2. 이름표가 hello-button 인 버튼과, message 인 글 상자를 찾아와.
> 3. hello-button 을 누를 때마다 횟수를 1 늘리고,
>    글 상자의 글을 "반가워요! 1번째 인사예요 😊" 처럼 바꿔 줘. (숫자 자리에는 지금까지의 횟수)
>
> 지켜 줄 것:
> - 초보자가 읽는다고 생각하고 한 줄마다 한국어 설명을 달아 줘. 이름은 쉬운 영어 단어로 지어 줘.
> - 배경색 버튼은 아직 건드리지 마.
> 먼저 계획을 보여 주고, 내가 확인하면 만들어 줘.
> ```

**프롬프트 점검표**: ✅ 이름표를 **그대로** 적었나? / ✅ **움직임 파일을 불러올 위치(웹페이지 맨 아래)** 를 적었나? / ✅ 이번 라운드에서 **하지 않을 일**(배경색 버튼)을 적었나?

> ⚠️ **`<script>` 는 `</body>` 바로 위!** 버튼이 **먼저 만들어진 다음에** JS가 버튼을 찾아야 해서예요.

### 4-2. 🧪 콘솔(Console)에서 에러 읽기 연습

> 💡 **에러는 컴퓨터가 주는 힌트**예요. 일부러 만들어 읽어 봅시다.

1. `app.js` 에서 `getElementById("hello-button")` 를 `getElementById("hello-buton")` 로 **틀리게** 바꾸고 새로고침.

3. 빨간 글씨 `Cannot read properties of null` 과 오른쪽 **`app.js:줄번호`** 가 보일 거예요. *"범인의 위치"* 를 알려 주는 탐정이에요!

🅿️ **에러를 AI에게 보여 주는 프롬프트 (에러 메시지를 통째로!)**
> ```text
> 브라우저 Console 에 이런 에러가 나. 원인이 뭐고 어떻게 고쳐야 해? 초보자 눈높이로 설명해 줘.
> (여기에 에러 메시지 전체를 붙여넣기)
> 파일은 아직 고치지 말고 설명만 해 줘.
> ```

### 4-3. 🅲 코드 읽기 — 한 줄씩 뜻 맞추기

기준 코드와 **비교하며 읽으세요.** (AI 코드가 달라도 같은 일을 하면 OK!)

**📄 app.js (기준)**

```javascript
// app.js - 버튼을 누르면 움직이는 페이지

// 1. 인사 횟수를 기억하는 상자(변수)
let count = 0;

// 2. HTML에서 필요한 부분을 이름(id)으로 찾아오기
const helloButton = document.getElementById("hello-button");
const message = document.getElementById("message");
const colorButton = document.getElementById("color-button");

// 3. 인사 버튼을 누르면 할 일
helloButton.addEventListener("click", function () {
  count = count + 1;
  message.textContent = "반가워요! " + count + "번째 인사예요 😊";
});

// 4. 배경색 버튼을 누르면 할 일
const colors = ["#eef3ff", "#fff3bf", "#d3f9d8", "#ffe3e3"];
let colorIndex = 0;

colorButton.addEventListener("click", function () {
  colorIndex = colorIndex + 1;
  if (colorIndex >= colors.length) {
    colorIndex = 0;
  }
  document.body.style.backgroundColor = colors[colorIndex];
});
```

> 📖 **새 용어 풀이**
> | 용어 | 쉬운 뜻 |
> |:--|:--|
> | **JavaScript(JS)** | 웹페이지에 **움직임**을 주는 언어 (HTML=뼈대, CSS=옷, **JS=근육**) |
> | **변수(variable)** | 값을 담아 두는 **이름표 붙은 상자** (`let count = 0;`) |
> | **함수(function)** | 이름 붙은 **할 일 묶음** (레시피) |
> | **이벤트(event)** | 클릭·키 입력처럼 **사용자가 한 행동** |
> | **배열** | 번호(0부터)로 순서가 있는 **값의 줄** `["a", "b"]` |
> | **조건문 `if`** | *"만약 ~라면 ~해라"* |
> | **콘솔** | 개발자용 **메모·에러 창** (`F12`) |

```text
 변수 = 이름표 붙은 상자              let count = 0;   →  ┌───┐
                                                          │ 0 │ ← count
 count = count + 1;  (꺼내서 1 더해 다시 넣기)             └───┘
 이벤트 = 초인종:  버튼.addEventListener("click", 할 일)
          누구에게?        어떤 일이?       그러면 뭘?
```

| 줄 | 뜻 |
|:--|:--|
| `let count = 0;` | `count` 상자를 만들고 0을 넣어요 |
| `document.getElementById("hello-button")` | 문서에서 id가 `hello-button` 인 요소를 **찾아와요** |
| `const helloButton = …` | 찾은 버튼을 `helloButton` 상자에 **넣어 둬요** |
| `addEventListener("click", function () { … })` | 버튼을 **클릭하면** 중괄호 안의 일을 해요 |
| `count = count + 1;` | 상자 속 숫자를 **1 늘려요** |
| `message.textContent = …` | 글 상자의 **글자를 바꿔요** |
| `"반가워요! " + count + "번째…"` | 글자와 숫자를 `+` 로 **이어 붙여요** |
| `colors[colorIndex]` | 배열에서 `colorIndex` 번째 색 (**0부터** 센다!) |
| `if (colorIndex >= colors.length) { colorIndex = 0; }` | 끝까지 가면 **처음으로** (순환) |

```text
 colors = [ "#eef3ff", "#fff3bf", "#d3f9d8", "#ffe3e3" ]
   번호       0           1          2          3        ← 0부터!
 클릭할 때마다:  0 → 1 → 2 → 3 → (4가 되면 if가 0으로) → 0 → 1 …
```

## 💪 도전 A · B (우수 학생용 중급 확장)

> 🧭 **도전도 두 레인으로!** ① 🅿️ **프롬프트 점검표**를 지켜 Antigravity에게 시키고 → ② 🅲 **코드 점검표**로 결과를 확인하세요. *(AI가 준 코드가 안 돌아가면 에러 메시지를 붙여 넣어 고치고, 마지막에 **내 말로 코드를 설명**해 보세요.)*
> ✍️ **프롬프트는 코드가 아니라 일상어로!** 아래 코드 조각은 *읽고 이해하기 위한 예시*예요. AI에게는 코드를 붙여 넣지 말고 **"무엇을 어떻게 되게 하고 싶은지"** 를 말로 설명해서 시켜 보세요.

### 💪 도전 A · "방문 횟수를 기억하는 카드" (`localStorage`)
지금은 **새로고침하면 횟수가 0으로 돌아가요.** 브라우저에 값을 **저장**하는 `localStorage` 를 써 보세요.

```javascript
// 불러오기: 저장된 값이 없으면 0
let count = Number(localStorage.getItem("count")) || 0;
message.textContent = "지금까지 " + count + "번 인사했어요";

// 저장하기: 횟수가 바뀔 때마다
localStorage.setItem("count", count);
```
**목표**: 새로고침해도 횟수가 **이어지도록** 만드세요. (`Number(...)` 는 글자를 숫자로 바꿔요 / `|| 0` 은 *"없으면 0"*.)
> 💭 생각해 보기: 친구 컴퓨터에서 내 사이트를 열면 내 횟수가 보일까요? (힌트: 저장 위치는 **누구의 브라우저**일까요?)

### 💪 도전 B · "랜덤 인사말 뽑기"
버튼을 누를 때마다 **여러 인사말 중 무작위로 하나**가 나오게 해 보세요.

```javascript
const greetings = ["안녕!", "반가워요!", "오늘도 힘내요!", "코딩 멋져요!"];

const pick = Math.floor(Math.random() * greetings.length);
message.textContent = greetings[pick];
```

| 코드 | 뜻 |
|:--|:--|
| `Math.random()` | 0 이상 1 미만의 **무작위 소수** |
| `* greetings.length` | 인사말 개수(4)를 곱해 0 ~ 3.99… 로 |
| `Math.floor(…)` | 소수점 **버림** → 0, 1, 2, 3 중 하나 |

**목표**: ① 인사말을 **내 말투 6개**로 늘리기 ② 같은 문장이 **연속으로** 나오지 않게 하기 (힌트: 이전 번호를 변수에 기억해 두고 비교!)
